## 一、本轮学习定位

C4（06-19）提出了三个"高阶武器"：SCM结构因果（do-calculus + TNCM-VAE反事实价格差）、KOL 3态HMM（静默→推广跃迁权重×3）、SIR传播模型（R₀定量社区共振）。C4-Re按C1-Re确立的视角——**"不是加更多工具，而是让信号源头更干净"**——审视这三个工具的**结构性缺陷**（含06-19自带的实证瑕疵：ACE报"0.32%/95%CI(0.12,0.52)"宽度达3倍、Elon转移矩阵为"估计"拍脑袋值），并给L0/L1/L2源头预防对照与ROI排序。

**核心命题：三个C4工具的共性源头问题是"数据源不满足模型需求"——A7只有web_search快照+价格K线，没有社区互动时序、没有转发网络、没有可干预的推文流。模型先于数据=结构性错配，落地即自欺。** 本轮结论与09-02（舆情C4-Re）一致：**能查表的就不训模型，能状态机的就不上HMM，能事件研究的就不做SCM。**

## 二、3条核心要点

### 要点1：SCM反事实因果——识别假设在KOL场景不成立，"反事实"不可证伪，事件研究法才是可落地子集

**结构性缺陷审视（6项）：**
1. **无混杂假设不成立（最致命）**：do(Tweet)的识别要求"发推与否与价格潜在结果独立"。但KOL发推时机本身由市场驱动——Elon在市场热点/币价上涨时更爱发言（双向因果：价格→推文 且 推文→价格）。观察数据无法识别方向，这正是A7"先涨后推"问题（C2-Re已识别）的因果版——SCM没有绕开它，只是换了个更贵的框架描述它。
2. **反事实不可验证（The Fundamental Problem）**：TNCM-VAE生成的"无推文世界"永远无法与真实对照——VAE潜空间高斯先验一旦错误，生成的反事实场景就是虚构叙事。8h+开发量产出一个**不可证伪的分数**，属于自欺式改进（与09-02要点3"更新了=更准的错觉"同构）。
3. **因果图中间节点全缺失**：06-19的因果图是 KOL推文→社区情绪→交易量→价格。A7的web_search是**快照非时序**，社区情绪序列、转发网络、逐笔成交量意图均无数据源——中间变量全缺，ACE估计依赖不可观测节点，等于用图的名义做回归。
4. **稀疏事件→功效不足**：单KOL单币种喊单事件年发生数次，ACE的95%CI宽到无决策意义（06-19自写0.32%/CI(0.12,0.52)，宽度3倍——报这种数本身就是误导，ZH会当精确值用）。
5. **处理效应异质性被平均化**：同一条推文在牛市vs熊市、BTC vs山寨、叠加其他KOL同喊时效果差10倍。单一ACE掩盖异质性→"平均因果效应"对**当下这一条**推文无预测力。
6. **评估泄漏**：用价格数据训练因果模型、再用价格反应验证告警=用结果验证结果（与08-28 MetaThresholdAdapter评估泄漏同病）。

**L0/L1/L2源头预防对照：**
| 层 | 预防 |
|:--|:-----|
| L0 | **弃SCM，用事件研究法**（08-19 C3-Re P1已选，本轮确认为SCM的可落地子集）：推文事件窗(±15min)配对对照窗(前24h同期)，做差分；不需要因果图、不需要反事实生成，识别假设弱得多（对照窗内无同币其他事件即可） |
| L1 | 事件窗内**混杂检查**：窗内是否叠加其他KOL喊单/重大新闻/交易所动作→叠加则标`[多事件混杂]`降级为参考，不单独归因；对照组诊断（C2-Re 08-05 P1：控制组与处理组基期相关性>0.6才有效） |
| L2 | alert因果标注透明化：只标"事件研究法差分结果"，**禁止报不可验证的反事实ACE**；方向性拆分（MIS_up/down，08-19 P4）保留 |

**应用结论**：SCM/TNCM-VAE归档为学术参考。A7要回答的因果问题（"这条推文带动的涨幅里有多少真因果"）用**事件研究法差分+混杂标注**就够，代码量20行，且每步可审计。06-19的P3(8h)/P4(24h+)两项正式驳回。

### 要点2：KOL行为HMM 3态——小样本+残缺观测下状态估计是幻觉，2维计数器+EWMA活跃度即可替代

**结构性缺陷审视（6项）：**
1. **观测残缺（最致命）**：HMM的"静默"状态对模型=无观测。但A7数据是web_search快照，本身就漏推文（15分钟轮询+搜索召回不全）——**无法区分"KOL真静默"与"A7没采到"**。状态估计建立在残缺观测上，静默→推广跃迁可能是漏采造成的假跃迁→按06-19规则权重×3=系统性误报源。
2. **小样本状态不稳**：Elon月均几十条推文、Saylor更少——3态×3转移矩阵=9参数+发射分布参数，用几十个样本训Baum-Welch→过拟合，状态序列估计抖动。06-19的转移矩阵自己都标注"估计"（实为拍脑袋）。
3. **非平稳/概念漂移**：KOL行为模式随时间剧变（Elon收购推特后风格、CZ退任后发言频率）。固定转移矩阵在模式切换后批量失效，需在线更新→引回09-02"模型悄悄变差"问题（漂移监控P7至今未落地）。
4. **状态≠驱动力错位**：权重×3的假设是"静默→推广跃迁影响最大"，但06-19没回测。直觉上"持续高频喊单"（一直推广）反而边际影响递减——**状态本身不是驱动力，推文内容+时机才是**。用行为状态当价格影响代理=错位变量。
5. **发射分布假设错**：转发量是重尾幂律、情感分数高度偏斜，假设高斯/类别发射分布→状态分类系统性偏。
6. **复杂度闸门触发**：A7的实时判断只需要"这位KOL最近N小时活跃度如何"——15分钟粒度下用滑动窗口计数或EWMA活跃度(β=0.94，08-19校核)就能算，**一个float变量解决，不需要隐状态推断**。30行hmmlearn落地后发现无序列数据可喂（同要点1缺陷3：数据源与模型错配）。

**L0/L1/L2源头预防对照：**
| 层 | 预防 |
|:--|:-----|
| L0 | **弃HMM**：per-KOL EWMA活跃度分数（推文计数+关键词强度加权，λ=0.94半衰期11.2天与信誉分同层，分钟级事件响应另走事件研究法——08-19 C3-Re双层分离已定） |
| L1 | 活跃度跃迁只做**权重微调(×1.3~1.5)不做×3**，且必须叠加价格位置验证才升告警级（防止漏采假跃迁直达告警） |
| L2 | 告警时标注KOL近期活跃度值+数据覆盖窗口（"近24h采到N条/覆盖M轮"），让ZH能看到残缺度，杜绝"静默KOL突喊=3倍权重"的幻觉告警 |

**应用结论**：06-19 P1（HMM 30行）驳回。要的只是"最近活跃度"这个标量，EWMA一个float；真需要状态机的那天（接入Twitter API流、无漏采）再评估HMM——**先补数据源，再谈隐状态**。

### 要点3：SIR传播模型——参数不可辨识+代理错位，R₀是假精确；多源独立计数(ISC)已是正确的定量共振

**结构性缺陷审视（6项）：**
1. **同质混合假设失效**：SIR假设人群均匀混合，但社交网络是异质图（粉丝聚类、回声室、机器人水军）。全局β掩盖网络结构——传播的"形状"远比"平均速率"重要，聚合模型给不出。
2. **参数不可辨识（理论硬伤）**：流行病学经典结论（NIH PMC9487859 "Limits of epidemic prediction using SIR"）——β与γ从单一感染曲线无法同时识别。A7能观测的只有价格消退时间（γ代理），β需互动率时序（无数据源）→β拍脑袋→**R₀=β/γ是假精确**，比不报更误导。
3. **代理变量错位**：06-19把β≈互动率、γ≈价格消退、S/I/R分群全是类比映射。价格消退≠情绪康复（价格回落可能因流动性/套利，情绪仍在）；用价格行为推断情绪传播=**测量的是市场不是情绪**。
4. **生态谬误**：R₀是宏观流行病参数（整个人群），A7要决策的是单条推文是否扩散——用聚合参数做微观事件告警（R₀>2→告警）是把人群平均当个体预测。
5. **单病原体假设**：市场参与者同时被价格本身、其他KOL、新闻、链上巨鲸轰炸，"感染"来源多元。单病原体SIR把价格波动全归因于该推文→高估传播→共振误判（A7误报类型3"单源误报高置信"的直接来源）。
6. **数据需求不满足**：SIR要连续感染人数时序（转发/提及/互动随时间的曲线）。web_search快照+URL去重给不出任何时序——06-19 P2"scipy 50行"落地即无数据可喂（与要点1/2同一结构性错配）。

**L0/L1/L2源头预防对照：**
| 层 | 预防 |
|:--|:-----|
| L0 | **弃SIR/R₀**：社区共振继续用**多源独立计数ISC**（07-22 C2-Re P2/08-14 C3-Re：独立来源数≥2同方向+来源信誉加权+转贴1/N折扣）——它要求的"独立来源数"正是A7 web_search能给的真实数据 |
| L1 | 共振强度改**事件类型特异性衰减**（08-14 P2：α按KOL 30min/监管24h分档）代替SIR的γ；传播扩散判断用"来源多样性"（不同媒体/社群域名数）而非感染速率 |
| L2 | alert只报可观测事实："该推文被N个独立来源同方向提及"，**禁止报R₀/β这类不可辨识参数**；单源=标`[单源信号]`维持现状 |

**应用结论**：SIR/R₀归档学术参考。A7的"社区共振"量化**已经**有正确实现——ISC独立源计数+来源信誉，比SIR更匹配数据源且可审计。06-19 P2（SIR 50行）驳回。真需要传播动力学的那天=接入Twitter API拿到转发/提及时序之后。

**与C1-Re核心命题的呼应**：三个C4工具的共性根源不是"过滤不够"，而是**模型先于数据**——SCM缺中间变量时序、HMM缺无漏采推文流、SIR缺互动率曲线。A7的数据源（快照级web_search+K线）决定了正确复杂度上限：事件研究法/EWMA/ISC恰好是这三个高阶框架在A7数据约束下的**正确降维**。驳回不是否定方向，是把工具放回它数据配得上的位置。
