# Blade 职责说明

## 一、每30分钟执行节点

每个节点执行流程：
1. 读取 coin_pool.json 获取当前待评估币种
2. 读取阶段分类（LATEST_PHASE.md）获取每币的阶段标记
3. 按 NAVIGATION.md §3-§4 规则判断进场/出场
4. 执行 Binance API 交易
5. 写入 TRADES.md
6. 写入 node_history.jsonl
7. 写入趋势数据

## 二、进场规则（总纲）

- **有动静就建仓** — 但动静不是"涨了"，是"有数据说它正要涨了"
- **可信度排序：** 放量突破 > 涨幅榜 > 聪明钱 > 舆情
- **F&G>50追涨，F&G≤20抄底**

## 三、出场规则（总纲）

- **-3%~-5%硬止损** — 不扛单
- **涨幅榜出TOP50** — 清仓
- **大盘跌(BTC-5%)** — 减半仓

## 四、记录要求

每笔交易必须记录到 trade_db：
- 入场时间/价格/原因/信号
- 出场时间/价格/原因
- 盈亏
- 经验教训
