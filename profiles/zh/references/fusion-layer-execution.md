# 方向融合层 — ZH总指挥核心产出（2026-05-17 老李确立）

## 一句话定义
每天早上05:30，ZH读A1/A7/A8/A9 + 自身赛道热度 + 全网搜索 → 合成「今日方向优先级」→ 给A2/A3作为方向锚。

## 为什么要这个层
```markdown
之前：
  A1采集一堆数据 → 没人读
  A7监控舆情 → 没人用
  A8看资金 → 没人管
  A9做研究 → 没人看
  
  所有采集的信号没有一步叫"所以今天该主攻什么方向"

有了融合层后：
  A1/A7/A8/A9全部产出 → ZH 05:30融合 → shared/direction_priority.md
    → A2(06:00)读：按权重分配扫描资源
    → A3(07:00)读：从高权重赛道优先精选
```

## 数据流
```
05:00  A1数据采集  →  profiles/a1-data/output/YYYY-MM-DD.md
05:00  ZH赛道评分   →  shared/hot_sectors.md
05:30  ZH方向融合   →  读A1 + A7 + A8 + A9 + hot_sectors + 全网搜索
                    →  四大师视角合成
                    →  write_file shared/direction_priority_YYYY-MM-DD.md
06:00  A2脚本评分   →  读 direction_priority.md → 按权重加分
07:00  A3精选       →  读 direction_priority.md → 高权重赛道优先精选
```

## 产出格式
```
shared/direction_priority_YYYY-MM-DD.md

包含：
- 宏观环境（F&G/BTC/BTC.D）
- 方向排序（赛道名 + 权重% + 理由）
- 不关注/减仓信号
- 今日异常信号
- 各数据源摘要
```

## 融合的数据源
| 数据源 | 内容 | 用途 |
|:-------|:-----|:-----|
| A1数据 (05:00) | F&G/费率/热度/宏观 | 判断整体市场环境 |
| A7舆情 (15min) | 名人的推/社群极端情绪 | 叙事判断 |
| A8资金 (15min) | 大额转账/聪明钱信号 | 资金流向判断 |
| A9研究 (每周) | 新工具/新数据源 | 长期方向判断 |
| 自身赛道热度 (05:00) | shared/hot_sectors.md | 赛道轮动判断 |
| 全网搜索 | 当日热点新闻 | 即时叙事判断 |

## 消费端
- **A2** (tools/a2_scoring.py): load_direction_priority() 解析权重 → 按赛道权重加分(0~+5)
- **A3** (profiles/a3-bull/AGENTS.md): 第0步读方向优先级 → 按高/中/低权重分类候选币 → 优先分析高权重赛道

## 四大师视角合成规则
每次合成方向优先级时必须过四问：
1. CZ交易视角：哪个方向有成交量、有真实交易？
2. V神本质视角：哪个方向有真实世界连接？
3. 徐明星生态视角：哪个赛道的人在扩张？
4. 孙宇晨趋势视角：哪个方向是未来趋势？

## 不做的
- 不替A2选币（A2自己算评分）
- 不替A3精选（A3自己做四维分析）
- 方向权重的总和必须=100%
