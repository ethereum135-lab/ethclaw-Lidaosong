## 🧠 三条核心判断逻辑（可直接用于系统）

### 规则1：「真实连接过滤层」— 不是TVL是用户活动

**V神哲学：** 一个项目的价值在于它连接了什么现实问题。不是TVL，不是价格，是**真实用户活动**。

**他的核心区分：**
- 地址数 ≠ 用户数（空投地址不是用户）
- TVL ≠ 价值（锁仓可能只是挖矿循环）
- 真正的用户是那些**因为功能而使用**的人

**可执行规则（A2 Stage2新增10%权重维度）：**

```python
# 候选人「真实连接」评分（0-100分，权重10%）
# 数据来源：Dune/Etherscan链上数据（通过A8数据管道）
def real_connection_score(coin_data):
    score = 0
    # 1. 活跃合约交互数（不是总tx，是24h独特合约交互）
    if coin_data["daily_contract_interactions"] > 1000:
        score += 40
    elif coin_data["daily_contract_interactions"] > 100:
        score += 20
    
    # 2. DApp多样性（超过1个类别）
    if coin_data["dapp_categories"] >= 3:
        score += 25
    elif coin_data["dapp_categories"] >= 2:
        score += 15
    
    # 3. 非空投用户占比（持有>30天未转移）
    if coin_data["retention_rate"] > 0.6:
        score += 20
    elif coin_data["retention_rate"] > 0.3:
        score += 10
    
    # 4. 治理参与率（投票者/持有者）
    if coin_data["gov_participation"] > 0.05:
        score += 15
    elif coin_data["gov_participation"] > 0.01:
        score += 8
    
    return min(score, 100)
```

**V神经典引用：** "If a project's main metric is its token price, it's likely a casino, not a product." — 2025年3月
