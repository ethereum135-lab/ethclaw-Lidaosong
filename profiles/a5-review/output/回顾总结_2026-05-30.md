## 第③步：系统改进建议（基于本周综合学习）

### 建议1：🔴 legacy仓位止损扫描器

**问题：** NIGHT单一交易-$129.17占本周亏损97.4%。它在系统中存在了多久没有人知道——**没有止损线、没有监控规则、没有预期记录。**

**解决方案：**
```bash
# 所有legacy仓位（无入场价的持仓）每8小时扫描
cd ~/zq_web4_trading_system && python3 -c "
# 伪代码
for holding in legacy_holdings:
    current_price = get_price(holding.symbol)
    if holding.last_known_price / current_price > 1.30:  # 跌超30%
        execute_clear(holding, reason='legacy_drawdown_30pct')
"
```

**受益Agent：** A4 Blade（执行清仓）+ FK风控（检测legacy跌幅）

### 建议2：🔴 F&G<25时禁用动量bypass

**问题：** 本周4笔动量bypass买入全部硬止损(-$9.57)，05-29报告已标记此问题但05-30仍然有类似案例(SAPIEN -5.24%)。

**解决方案：** 在A4 AGENTS.md中添加规则5：
```
## 规则五：极端恐惧禁止动量bypass
当F&G<25时，任何24h涨幅>15%的STRONG信号买入自动降级为SIGNAL，
需额外确认（如2m RSI回调至<30方可执行）。
```

### 建议3：🟡 增加退出信号「Lollapalooza叠加检测」

**问题：** E系列(E2/E3/E4)单独触发正确率1-4%，无多因素共振机制。

**解决方案：**

- 单一E2或E3 → 继续持有或减仓50%
- 止盈系统不依赖此规则（规则先行）

### 建议4：🟢 本周止盈系统"零错误"——继续保持
