# 四位大师思维框架 — 可执行版（2026-05-17）

> 目的：不是分析他们，是让他们长在系统里。
> 每次看市场/看数据/做决策时，这四副眼镜自动戴上。

---

## 1. 赵长鹏（CZ）— 交易核心思维

**一句话：** 一切决策围绕"交易能不能发生"。

### 可执行规则

| 场景 | CZ会怎么想 | 系统执行 |
|:-----|:-----------|:---------|
| 看到一个币在涨 | "有成交量吗？能交易吗？" | A2评分：成交量权重>市值权重。量比<1.0的涨=假涨 |
| 看到一个币很便宜 | "便宜不等于能赚钱，没有流动性的便宜是死钱" | A3选币：排除日成交量<$1M的币 |
| 市场恐慌(F&G<30) | "恐慌才有交易机会——别人不敢买的时候才是好时机" | A3在F&G恐惧时：不是空仓，是放宽条件去找动量突破 |
| 持仓亏损 | "亏损不是风险，不能交易的亏损才是风险" | A4：不能交易的尘仓位及时止损，释放资本 |
| A3推荐/不推荐 | "交易量决定一切——有量的币才是真正的机会" | A3四维分析：量价结构40%权重（最高），叙事权重只占20% |

### 适用于
- A2评分权重设计
- A3候选池过滤条件
- A4买卖决策中"量"的优先级

## 2. V神（Vitalik Buterin）— 本质连接思维

**一句话：** 每个币/每个项目的价值在于它连接了什么现实问题。

### 可执行规则

| 场景 | V神会怎么想 | 系统执行 |
|:-----|:-----------|:---------|
| 看到一个币在涨 | "它解决了什么实际问题？连接了什么真实需求？" | A3叙事分析：优先选有真实应用场景的币（DeFi/GameFi/RWA/算力），回避纯概念币 |
| 看到一个meme币暴涨 | "没有真实连接的涨，只是情绪的波动" | A3四维分析：叙事逻辑维度给meme币低分（除非有大规模采用证据） |
| AI赛道走强 | "AI是真需求还是泡沫？——看有没有实际的产品在跑" | A9学习扫描：定期查AI赛道项目的实际进展（TVL/用户数/收入），不是只看币价 |
| 一个项目只拉盘不做事 | "没有现实连接的项目不值钱" | A2过滤：排除只有推特热度但GitHub无更新的项目 |

### 适用于
- A3叙事分析逻辑
- ZH行业研判中的"真实性判断"
- A9学习扫描的方向

## 3. 徐明星（欧易）— 生态人才思维

**一句话：** 一个币/一个项目的价值，看它的生态和"从哪出来的人"。

### 可执行规则

| 场景 | 徐明星会怎么想 | 系统执行 |
|:-----|:--------------|:---------|
| 看到一个项目 | "它的生态是什么样的？有开发者吗？有用户吗？" | A3叙事分析时：检查GitHub活跃度/社区规模/合作伙伴 |
| 一个新公链出现 | "谁在这个链上做项目？有好的团队迁移过来吗？" | ZH行业扫描：新公链/新赛道出现时，先看"谁进来了" |
| 币安和欧易的差异 | "竞争的本质是生态——谁有更多项目/用户/人才" | 不要只看币安一个交易所的流动性。如果有日成交量$0.5M但跨交易所都有交易对的币，比单所$5M的币更健康 |
| 团队背景 | "这个团队做过什么？从哪来的？" | A3选币时：如果可以查team背景，优先选有知名背景的团队 |

### 适用于
- A3的叙事分析补充（生态维度）
- ZH每周研判中对项目的深度评估

## 4. 孙宇晨 — 趋势预见思维

**一句话：** 现在大家都在做的不做，做别人还没看到但一定会来的。

### 可执行规则

| 场景 | 孙宇晨会怎么想 | 系统执行 |
|:-----|:--------------|:---------|
| 大家都在追AI概念币 | "AI已经热了——真正的机会在下个还没人注意的方向" | ZH不要把全部注意力集中在最热赛道。每天留出20%精力扫描"快变热"的赛道（连续2天评分上升的非热门赛道） |
| 当前市场恐慌 | "恐慌出清后，下一个周期的基础就在此刻" | ZH应预判下一个热点：不是抄底现在的币，是关注"恐慌过去后资金会流向哪里" |
| 看到一个新趋势 | "这个趋势在未来几年会变成什么样？" | ZH行业研判的"趋势预判"部分：不只是"今天怎么样"，还要想"3个月后会怎么样" |
| 一个项目用新方法解决旧问题 | "这是未来——用新维度的竞争" | A9学习扫描应该关注的不只是"新工具"，还有"新方法/新范式" |

### 适用于
- ZH的10:00行业研判中的"趋势预判"部分
- A9每周学习扫描的方向（关注"新范式"多于"新工具"）
- A3在对非热门赛道的候选币做评估时，考虑"这个赛道会不会热起来"

---

## 如何使用这个框架

### 对ZH（总指挥）

每天10:00行业扫描时，不只是回答"今天市场怎么样"，还要回答：

```
CZ视角 → 有什么正在发生的有量的交易机会？
V神视角 → 这些机会背后有真实连接吗？
徐明星视角 → 这些币/赛道的生态在扩张还是萎缩？
孙宇晨视角 → 下一个热点可能在哪？我是不是在看已经热了的东西？
```

### 对A3（牛币官）

四维分析时，额外加入这三个检查：

```
① 这个币有足够的成交量支撑购买和卖出吗？（CZ:可交易性）
② 它有真实的应用场景或生态吗？（V神+徐明星:本质连接）
③ 它所在的方向，3个月后还会热吗？（孙宇晨:趋势判断）
```

### 对A4（交易官）

持仓评估和买入决策时：

```
CZ → 这个仓位的流动性够吗？能快速退出来吗？
V神 → 我买的不是K线，是这个币背后的价值连接。这个连接还在吗？
```

### 对A9（学习扫描）

每周学习时，不再只搜"新工具"，还要搜：

```
① 新的交易范式/策略？（孙宇晨关注点）
② 新的生态项目/链在发展？（徐明星关注点）
③ 哪些新项目在连接现实问题？（V神关注点）
```
