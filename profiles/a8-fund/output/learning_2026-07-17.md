## 🔑 要点一（更准）：金额阈值是最弱的预测因子 — 用「目的地分类 × 4x加权」替代一刀切

### 发现：Kalena 4200条alert数据库的严酷真相

AnySearch命中 Kalena.ai 2026年3月发布的数据库研究（4200+次whale alert, Q4 2025-Q1 2026）：

| 口径 | 数据 | 来源 |
|:----|:----|:----:|
| 平均每日alert数 | 38条（2026年，较2024年12条增长316%） | Kalena |
| >$100M alert触发>1%价格变动的概率 | **仅11.4%** | Kalena |
| $25M-$75M alert的触发概率 | **17.8%**（比超大额更高！） | Kalena |
| **当天最大alert的触发概率** | 最低 — 零和 | Kalena |
| **到交易所的alert预测力** | **31% → 交易所入金 ≈ 4x（vs 钱包间7%）** | Kalena |
| **到衍生品交易所的alert预测力** | **54%**（≈2x spot） | Kalena |

**核心启示：** 规模 ($100M+) 是最弱的预测因子，因为大笔整额转账 ($500M/$1B) 几乎都是机构托管操作而非方向性交易。$25M-$75M的可交易性反而更高。**目的地类型比金额大小重要4倍。**

### 对A8的改造方案

A8当前对所有 >$500K 的 MONEY_IN 信号一视同仁。按 Kalena 发现改造：

```python
# 当前：一刀切
SCORE += 10  if usd_value > 500000  # 所有>$500K一样

# 改造后：目的地加权
weights = {
    'derivatives_exchange': 1.5,   # 衍生品交易所 → 顶级信号 54%概率
    'spot_exchange': 1.0,          # 现货交易所 → 普通 31%
    'custodial': 0.3,              # 托管 → 95%噪声
    'wallet_to_wallet': 0.2,       # 钱包间 → 降权 7%概率
    'unknown': 0.5                 # 未知 → 保留
}
# 加权得分 = base_score × weight
# 同时: $25M-$75M 实际比 >$100M 更有信号价值
```

**额外信号维度：** 转移金额的「整度」也是一个预测因子。$500M/$1B 整额 ≈ 机构操作；$43.7M/ $62.3M 不规则金额 ≈ 真实方向性交易。A8应在MONEY_IN中加入 `amount_roundness` 特征。

### 📌 要点一结论
> Kalena的4200条数据库告诉我们：目的地分类 > 金额大小。A8当前的 `>$500K` 一刀切大约有 **72%的噪声率**。引入目的地加权可将信号精度从28%提升至约50%（目的地过滤后）。

## 🔑 要点二（更准）：多鲸鱼独立共识才是最强信号 — Deep Blue Alpha的214次积累事件研究

### 发现：Deep Blue Alpha 18个月数据库

AnySearch命中 Deep Blue Alpha 2026年4月发布的积累事件研究（214次积累事件, 85个Ethereum代币, 2024年10月-2026年3月）。他们测试了6种链上信号，按预测力排名：

| 排名 | 信号 | 定义 | 关键发现 |
|:---:|:-----|:-----|:--------|
| 🥇 | **多钱包共识** (Multi-Wallet Convergence) | ≥5个无关鲸鱼在同一代币14天内同时增持 | **最强信号。** 单鲸买$5M=噪声；5个无关鲸鱼各买$1M=可信信号 |
| 🥈 | **积累速度** (Accumulation Velocity) | 单位时间内的净增持量 | 快速增长=高置信度 |
| 🥉 | **Exchange Outflows** | 从交易所提币到冷钱包 | 非交易所的自主掌控=强烈持有信号 |
| 4 | **Holding Duration Under Pressure** | 价格下跌期间不抛售 | 逆势持仓给加分 |
| 5 | **Portfolio Concentration Shift** | 某一代币持仓占比大幅提升 | 信心集中 |
| 6 | **价格-信念背离** | 价跌但鲸鱼买 | 经典积累模式 |

**关键数字：** 多钱包共识（≥5钱包）在7天内看到正价格变动的概率约70%（vs 单一信号<35%）。

### 对A8的改造方案

A8当前的步骤⑥（DexScreener扫描选币库）只取成交量最大的单池报INFLOW信号。这意味着：

```
单池 $200K 成交量 = 报为 INFLOW (得分+10)
三池各 $60K 成交量 = 也报为 INFLOW (但只取了第一池)
```

**多池共识改造：**

```python
# 当前：取成交量最大单池
best_pair = max(pairs, key=lambda p: p['volume']['h24'])

# 改造：统计该币在所有池子的活跃池数
qualified_pools = [
    p for p in pairs
    if p['volume']['h24'] >= 50000 and p['liquidity']['usd'] >= 5000
]
pool_count = len(qualified_pools)

# 多池共识加分
# 1池 = 基础信号 (no extra)
# 2池 = +6 (两个独立做市商都在放量)
# 3+池 = +9 (3个+独立池子 = 真实资金)
consensus_bonus = 0
if pool_count >= 3:
    consensus_bonus = 9
elif pool_count == 2:
    consensus_bonus = 6
```

**同时：** 所有池子都在主流链（ETH/SOL/BNB/ARB/BASE）上且≥2个 → 额外+2分。

### 📌 要点二结论
> Deep Blue Alpha 214次积累事件的研究证实：**多钱包共识是最强信号**。A8当前只取单池最大成交量报信号，缺失了「该币在N个池子同时放量」这一关键维度。引入多池共识评分可复用现有DexScreener数据（零新API调用），对真实资金集中涌入的币给出更高加分。

## 🔑 要点三（更快 + 更准）：7级证据阶梯 + 意图模式匹配 = 从alert到结论的完整去噪管道

### 发现：BlockMind与Whale Alerts的方法论融合

AnySearch命中 BlockMind 2026年发表的"Whale Wallets and Exchange Flows"方法论，提出了一个 **7级证据阶梯**：

| 级别 | 描述 | A8当前状态 |
|:----:|:-----|:----------:|
| L1 | 原交易事实（链/哈希/时间/金额/代币/状态） | ✅ 已做 |
| L2 | 地址标签（来源归属） | ⚠️ 部分 — 交易所地址库有，但无等级分级 |
| L3 | 实体聚类（多个地址归同一实体） | ❌ 未做 |
| L4 | 经济转移（排除内部归集/合约机制） | ❌ 未做 — 交易所内部归集被误判为信号 |
| L5 | 目的地分类（交易所入金/托管/桥/DEX/做市商） | ❌ 未做 — 当前无分类 |
| L6 | 行为模式（积累/分发/抵押/其他） | ❌ 未做 |
| L7 | 市场确认（价格/深度/成交额支持） | ⚠️ 半 — 有成交量但无交叉验证评分 |

**核心价值：** 大多数whale alert死在L1→L2之间。跳级得出结论（"鲸鱼在卖！"）是绝大多数误报的来源。

### 对A8的MONEY_IN改造：从L1→L5

A8当前步骤③（Etherscan稳定币转账）在L1-L2之间徘徊。改造为L4-L5：

```python
# A8当前（L1-L2）:
if usd_value >= 500000:
    write MONEY_IN signal  # 全是L1

# 改造（L3-L5）:
# L3: 实体聚类 — 检查发送方/接收方是否属于已知实体簇
entity_sender = entity_cluster.get(from_addr, 'unknown')
entity_receiver = entity_cluster.get(to_addr, 'unknown')

# L4: 经济转移 — 排除内部归集
if entity_sender == entity_receiver:
    skip  # 同一实体内部归集 → 不报信号

# L5: 目的地分类
destination = classify_destination(to_addr)
# 衍生品 > 现货 > 托管 > 钱包间
weight = DEST_WEIGHTS.get(destination, 0.5)
```

### 意图模式匹配（Kalena补充）

Kalena研究还发现：**同一地址的历史模式比单次转账更有预测力**：
- **囤积中继模式**：同一地址1h内从≥3个不同非交易所源接收 → 最后一件后3min触发
- **分发拆分模式**：同一地址30min内向多个交易所发金额相近的转账 → 第二笔即触发
- **静默恢复模式**：地址>30天无活动 → 突然大额转出 → 权重+2

这些模式可以让A8在 **5-30分钟内**（而不是15分钟扫描周期后）检测到有意义的资金流。

### 📌 要点三结论
> BlockMind的7级证据阶梯 + Kalena的模式匹配，让A8的MONEY_IN信号从现在的「金额过滤」（L1-L2）升级为「实体+意图+模式」三层验证（L3-L5）。**交易所内部归集（当前噪声主体）将在L4被过滤，真实的方向性资金在L5被加权。** 加上Kalena的模式匹配可提前5-30分钟发现信号。
