# 每日复盘标准：涨幅榜 vs 账户交易时机验证

> **性质：** 永久标准，所有Agent和Commander必须执行
> **确立日期：** 2026-06-05（老李确立）
> **核心：** 复盘不是事后统计赚亏，是审问每笔交易的时机质量
> **对齐铁律六：** 本标准是铁律六「每日盈利自检」的具体操作流程。铁律六问「为什么盈/为什么亏」，本标准通过审问时机质量来回答那个问题。
> **对齐WORK_STANDARD.md：** WORK_STANDARD.md第六章定义每日复盘流程模板、第十一章定义「复盘是提取信号」。本标准是那些通用流程的**具体执行标准**——每次复盘必须按本标准审问时机质量。

---

## 一、复盘回答的唯二问题

每一天的复盘，只回答两个问题：

### Q1：快涨时建仓了吗？
**检查方式：** 持仓的币，当时是什么价格进的？
- ✅ 刚启动进场（+3%~+15%，量比>1.5x，趋势向上，有A7/A8打标支撑）
- ❌ 追高进场（已经+40%以上的泵顶）
- ❌ 拿早了进场（横盘/下跌，不是快涨时刻）
- ❌ 假刚启动进场（phase classifier说刚启动但即刻反转）

**涨幅榜对照：** 持仓在榜→证明市场验证了我们的建仓是对的。持仓不在榜→我们可能不是在快涨时建的仓。

### Q2：快跌时清仓了吗？
**检查方式：** 清仓的币，是为什么清的？
- ✅ 硬止损触发（-5%~-8%）
- ✅ 轮换弱仓（信号减弱→释放资金转更强信号）
- ✅ 机械退出（BTC-5%→减半仓）
- ❌ 利润冒了就清（有盈利就跑了，但信号还健康）

**涨幅榜对照：** 不在榜的持仓→是否已经该清没清？

## 二、复盘执行流程

```
日终数据采集（23:00后）
    ↓
① 涨幅榜TOP20 vs 持仓对比
    ↓
② 每笔持仓审问：建仓时机（Q1）
    ↓
③ 每笔清仓审问：清仓时机（Q2）
    ↓
④ 诊断：能力缺口是什么？
    ↓
⑤ 记录到复盘报告
```

### 步骤①：数据采集
- 涨幅榜TOP20（交易所数据）
- 当前持仓列表（node_state.json）
- 今日交易记录（TRADES.md）
- 建仓/清仓理由（trades json）

### 步骤②：建仓时机审问
对每个持仓币：
```
涨幅在榜吗？
  ├─ ✅ 在榜：我们建仓时是快涨时吗？
  │     ├─ 当时建仓价在涨幅0-15%区间 → 快涨建仓 ✅
  │     └─ 当时建仓价已很高 → 追高 ⚠️
  └─ ❌ 不在榜：建仓时机可能错了
        ├─ 建仓后一直跌 → 不是快涨时进的 ❌
        ├─ 建仓后平盘 → 还没到快涨时刻 ⏳
        └─ 建仓后涨过又跌回去了 → 拿晚了 ❌
```

### 步骤③：清仓时机审问
对每笔今日清仓：
```
清仓理由是什么？
  ├─ 硬止损/止损 → 快跌清仓 ✅
  ├─ 轮换弱仓 → 合理轮换 ✅（但要确认轮进去的更强）
  ├─ 机械退出(BTC-5%) → 按铁律执行 ✅
  └─ 其他 → 审问：是否该清？
```

## 四、铁律

1. **复盘终点不是赚亏，是时机质量。** 赚了但追高进场=危险的好运气。亏了但快跌清仓=正确的风控。
2. **不写长篇分析。** 报告要让人一眼看出：哪些是真刚启动、哪些是假刚启动、明天怎么减少假刚启动。
3. **连续3天复盘质量差（建仓准确率<60%）→ 触发全链审查。**
4. **复盘发现的问题必须转化为明天的行动，不能只记录不改。**
