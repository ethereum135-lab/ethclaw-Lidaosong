## 五、核心能力一览

### 数据分析能力
- 从TRADES.md解析买卖对，计算准确P&L
- 匹配买入记录（时间在前+币种相同）
- 退出质量分类：correct(>+3%) / neutral(-1%~+3%) / wrong(<-1%)

### 经验值提取
- 每笔卖出后运行analyze-recent-sell.py --batch
- 自动写入JSON + 更新MASTER_EXPERIENCE.json
- 已累计分析**305笔**交易经验值

### 数据质量检测（DQW）
- **价格比检测**：sell/buy >10x 或 <0.1x → Column Shift
- **数量比检测**：sell_qty/buy_qty >5x 或 <0.2x → 列错位
- **零值价格检测**：buy==0 或 sell==0 → 精度截断

### 每日复盘
- 7章节标准模板：交易总览/信号分析/经验值检查/系统状态/问题发现/明日计划/评分
- 6步标准流程（--batch → --daily → DQW+archive → 写报告 → --master → 特殊场景校验）

### 因果链分析
- 区分"系统问题"和"偶然波动"
- 发现低波资产E3过灵敏（XAUT案例）
- 识别列移位脏数据规律

### 自检体系
- 每日自检（17:00）：6文件+产出一致性+DQW+archive+学习
- 可重复self_test.py自检

## 九、真实经历库

| 经历 | 发现 | 处理 | 教训 |
|:-----|:-----|:-----|:-----|
| LINK买入匹配错误(05-11) | get_last_exit()用了错误buy(时间在后) | 加入time< sell_time条件 | 高频交易中buy匹配必须检查时间顺序 |

| Column Shift(05-11 15:30-16:30) | UNI/AAVE/GALA三笔虚假P&L | DQW框架标记1星 | 同一批次的qty比是可靠检测指标 |
| SHIB精度截断(05-11 16:00) | buy/sell都在$0.0000 | 标记"精度不足" | <$0.0001的币需要更多小数位 |
| XAUT低波误触(05-11 16:30) | E3在30分钟对黄金锚定币触发 | 提出波动率校准建议 | 不同波动率品种需要不同E3阈值 |
