## 第一部分: 动量策略深度消化

### 1. 动量排序（Momentum Ranking）— 核心机制

**核心思想:**
> 过去N个月的赢家，在未来M个月继续跑赢输家（Jegadeesh & Titman 1993）

**关键参数:**
- 回看窗口（Ranking Period）：过去3-12个月
- 持有窗口（Holding Period）：持有1-12个月
- 常见组合: 6-1（用过去6个月排名，持有1个月）

**实现步骤(以6-1为例):**
```
第1步: 对每个币种，计算过去6个月总收益率
第2步: 按收益率排序，Top 20% = 赢家，Bottom 20% = 输家
第3步: 做多赢家组合，做空输家组合
第4步: 每月再平衡一次
```

**在crypto市场的特殊性:**
- 传统动量回看期偏长（6-12月），crypto加速需缩短（1-3月）
- crypto输家组合做空成本高（资金费率），更适合纯多赢家策略
- 动量崩溃（Momentum Crash）在crypto中更频繁——暴跌后反弹时动量最差
- 牛市中动量策略表现极佳，熊市中转空头

### 2. 因子动量（Factor Momentum）— 比币种动量更稳定

**核心思想:**
> 不是币种本身的动量，而是"属性因子"的动量。如果某种因子（如小市值因子）在最近表现好，未来继续表现好。

**与币种动量的区别:**
| 维度 | 币种动量 | 因子动量 |
|:-----|:---------|:---------|
| 对象 | 单个币 | 一组币的共同特征 |
| 信号 | 价格涨幅 | 因子收益率 |
| 稳定性 | 低（单个币容易掉头） | 高（因子变化慢） |
| 容量 | 小 | 大 |
| crypto适用性 | 高波动，适合短线 | 中，因子数据难获取 |

**适用因子方向（crypto领域):**
- 动量因子 — 强势币延续 → 加仓
- 低波动因子 — 波动率低的币更稳 → 底仓
- 资金流因子 — 聪明钱流入 → 跟买
- 市值因子 — 小市值高弹性 → 趋势加速期适用

**对我们的意义:** A3精选本质已经在做因子动量——A2筛出候选池（因子筛选），A3精选出牛币（动量排序）。区别是A3用手工分析，因子动量要求量化系统。

### 3. 行业轮动（Sector Rotation）— 最适合当前系统

**核心思想:**
> 资金在板块之间迁移，跟踪板块相对强弱，把资金配置到最强板块。

**经典轮动顺序（传统金融):**
```
经济复苏期: 金融→科技→消费品
经济扩张期: 科技→工业→原材料
经济顶峰期: 能源→大宗商品
经济衰退期: 防御板块（医疗/公用事业）
```

**crypto板块轮动（我们的场景):**
```
BTC企稳→资金流向大市值（BTC/ETH/SOL）
BTC突破→资金涌向Layer1（公链）
Layer1涨完→轮动到Layer2（ARB/OP）
Layer2涨完→轮动到DeFi（UNI/AAVE/CRV）
DeFi涨完→轮动到Meme/小市值资产
BTC回调→资金回流BTC/USDT避险
```

**当前我们在哪个阶段?**
- BTC $81,113 — 震荡偏弱（5月6日-$83K→5月13日-$81K）
- 大盘环境: 无突破信号，F&G 48（恐惧→中性过渡）
- 无新叙事启动，资金分散
- → 处于"横盘/无轮动期"——板块轮动策略暂时无效，适合均值回归

### 4. 动量崩溃（Momentum Crash）防御

**动量策略最大的敌人:** 市场剧烈反转时（暴涨后暴跌），追高买入的动量仓位全部被套。

**防御方法:**
| 方法 | 说明 | 接入难度 |
|:-----|:-----|:---------|
| RSI过滤 | 只买入RSI 40-60的币（不追高） | 低（已有RSI数据） |
| 波动率调整 | VWAP标准差突破时减仓 | 中（需波动率计算） |
| 分步建仓 | 首次建仓30%，趋势确认再加 | 低（手动可实现） |
| 时间截断 | 持有超过N天强制卖出 | 低（可设在SOUL） |
| 多信号确认 | 需要趋势+量+情绪三重确认 | 中（需量化实现） |
