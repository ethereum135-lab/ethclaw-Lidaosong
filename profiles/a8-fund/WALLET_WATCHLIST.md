## 🧠 聪明钱主动发现方法（v4 升级 — L2链信号分离）

> 在被动追踪已知地址之外，新增主动发现机制：通过DexScreener扫描异常代币 → 三路分类反查

### 流程 Pipeline

```
① DexScreener 扫描（每小时代币搜索）
   ├─ 搜索关键词: SOL/USDC/WETH/BONK/WIF/PEPE/BOME/DOGE/TURBO/MOG/SHIB/FLOKI
   ├─ 过滤条件: buy_sell_ratio ≥ 2.0 AND liquidity ≥ $10,000
   └─ 输出: 符合条件代币的 chain/symbol/contract/ratio/volume/liquidity/price

② 三路分类（v4 关键改进 — 不再全部走Etherscan）
   ├─ ETH主网（ethereum/eth）
   │  └─ Etherscan tokenholderlist → Top 5 持有者 → SMART|HOLDER
   ├─ SOL链（solana）
   │  └─ Helius getTokenLargestAccounts → Top 5 持有者 → SMART|HOLDER
   └─ L2链（base/arbitrum/polygon/optimism/bsc等所有其他链）
      └─ 不查持有者 → 记录买压信号本身 → SMART|L2_SIGNAL
      └─ L2合约地址在主网上不存在, 查了也是空结果
      └─ 买压数据本身即足够, A3选币可直接参考

③ 结果写入 a8_data_snapshot.json → "smart_money" 键
   ├─ SMART|INTERESTING: 所有链的异常买压代币(通用信号)
   ├─ SMART|HOLDER: ETH主网/SOL链的Top持有者
   └─ SMART|L2_SIGNAL: L2链的代币买压(不查持有者)

④ A3牛币官读取
   └─ A3在步骤0.5读取fund_flow.md的📡L2异常买压+🧠聪明钱发现章节
   └─ 候选币有买压信号 → 动量分+10
```

### 信号格式

| 字段 | 示例 | 说明 |
|:----|:-----|:-----|
| `SMART|INTERESTING` | `SMART|INTERESTING|solana|PEPE|...|2.0x|5000|15000|0.000004` | 异常代币(链/币名/合约/买售比/成交量/流动性/价格) — 所有链通用 |
| `SMART|HOLDER` | `SMART|HOLDER|PEPE|solana|AddrX|5.2%|100000` | Top持有者(币名/链/地址/持有占比/数量) — 仅ETH主网/SOL链 |
| `SMART|L2_SIGNAL` | `SMART|L2_SIGNAL|base|PEPE|0x...|2.0x|12000|256000|0.000000004` | L2链异常买压(链/币名/合约/买售比/成交量/流动性/价格) — 仅L2链 |

### 与已有监控的协同

- **DexScreener** 交叉验证交易活跃度（已有监控规则中的第5行）
- **Etherscan V2** 使用已有 API Key（非新增成本）
- **Helius**（SOL链）免费 25K 请求/天，用于反查 SOL 代币持有者
- 发现的地址可人工审核后加入 WALLET_WATCHLIST 地址库
