# ZQ Web 4.0 核心档案：三阶段复利实战工作流

## 一、 战略目标 (核心价值观：100万U实现路径)
1. **阶段一 (M1)**: 430U -> 10,000U。切入口：50个活跃币种，30分钟节点，每次3个，数据驱动。
2. **阶段二 (M2-M3)**: 1万U -> 10万U。延伸：竞猜板块、适度杠杆、拉长持仓周期。
3. **阶段三 (M4+)**: 10万U -> 100万U。全赛道覆盖、盈利包方案、合约对冲。

## 二、 强制工作流 (Socratic 6-Step Loop)
**质疑 -> 澄清 -> 验证 -> 发现问题 -> 修复再验证 -> 归档**
- **严禁**：只说不做、不核实汇报。
- **要求**：每一个具体任务（如买入KAT）必须记录到 `/audit/history.md`，包含：入场价、卖出价、盈利归因。

## 三、 数据档案三级管理制度
- **重要数据 (Important)**: 经验证确实盈利的信号源（核心名人、顶级KOL脉冲），记录到永久记忆，形成全员执行SKILL。
- **参考数据 (Reference)**: 未经实测的设想或新信源，先行小单验证，成功后晋升重要区。
- **一般数据 (General)**: 市场噪音，不准记录，不准干扰决策。

## 四、 核心数据来源矩阵
1. **官方&深层**: 推特/群聊官方动态、各国政策、名人言论。
2. **全网热点**: 第三方权重网站、KOL视频分享、市场情绪。
3. **资金流向**: 聪明钱包追踪、大户异动。

## 五、 策略落地与责任制
- **责任到人**: 每一次扫描必须有执行依据，每一笔盈亏必须有复盘归因。
- **独立进化**: 系统必须能够自动判定目标、自动执行、老李只看总结。不问就不动视为失职。
