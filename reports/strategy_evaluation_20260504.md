## 二、选币库评估：6AND+12维评分

### 评分分布（202次买入）

| 评分区间 | 数量 | 占比 | 胜率 | 平均P&L |
|:---|---:|:---:|:---:|:---:|
| >=80（高分） | 49 | 28% | 35% | +0.598% |
| 60-80（中分） | 81 | 46% | 31% | +0.051% |
| <60（低分） | 26 | 15% | 27% | -0.234% |
| 评分不明 | 46 | - | - | - |

**结论：评分系统有部分预测能力，但效果微弱。** 高分>=80的胜率35% vs 低分<60的27%，相差仅8个百分点。且平均P&L只有+0.6%——正期望值极低。

### 问题1: 评分权重有偏差
```
当前权重：成交额排名(40) + RSI(20) + 量比(20) + 趋势(20)
```
趋势加分最高20分，但**趋势是导致E3退出的最大元凶**（73%的E3退出买在趋势=1/2）。系统给"买在趋势中段"加了20分，这导致评分虚高但实际亏损。

### 问题2: 缺少"趋势年龄"因子
一个趋势持续了N个30分钟节点，其反转概率随N增大。当前系统完全不考虑这一点。

### 量化False Positive（高评分但亏损的典型案例）
```
ORCA: 评分106-112 | 买入trend=2 → 被E3/E2卖 | 亏损 -1.3%~-2.0%
ORCA评分112买入，但这是trend=2（已强涨），下个节点趋势反转
→ 趋势加分给了20分满分，但这20分是最危险的分
```

## 三、买入评估：持仓时间 + skip-held-coin

### 持仓时间分布（160笔买入→卖出对）

| 持仓时间 | 数量 | 占比 | 含义 |
|:---|---:|:---:|---|
| <30分钟 | 3 | 2% | 极速卖出 |
| **30-60分钟** | **78** | **49%** | **买入后1-2节点内卖出** |
| 60-120分钟 | 42 | 26% | 中线 |
| >120分钟 | 37 | 23% | 长持 |

**平均持仓：105分钟。** 49%的交易在30-60分钟内结束。

这意味着：系统买入后最多持续1-2个30分钟节点就被卖出。持仓时间保护期（90分钟放宽阈值）理论上应该保护新入场币，但从数据看，大量币在30-60分钟内就被E3或E2或E4打掉了——**保护期可能没有生效或阈值太严**。

### skip-held-coin问题
同一种币一天内被买入3次以上：
```
2026-05-02: DOGE 3次买入 | ORCA 3次买入
2026-05-03: DOGE 4次买入 | XRP 3次买入 | LTC 3次买入
```

**系统存在"反复买入→E3卖出→再买入→再E3卖出"的死循环。** 这说明skip-held-coin没有起作用，或者理解有误——系统卖完一个币后立即又可以重新买入，没有冷却期。

### 进场条件问题：6AND缺失关键维度

当前6AND条件：
1. ✅ RSI 20-70
2. ✅ 量比 >= 1.0
3. ❌ **趋势 >= 0 (太松)** — 应该改为"趋势刚从平转升"
4. ✅ 价格位置 30-70%
5. ✅ Top50
6. ✅ 24h涨幅 -5% ~ +15%

**缺的维度：**
- 趋势持续时间 — 不知道这个趋势是新生的还是老化的
- 资金费率 — 没接进来做买入过滤
- 主动量能确认 — 量比>=1.0太松，应该>=1.5才有意义

## 四、卖出评估：E1-E6触发统计

### 全周期退出信号频率（165次卖出）

| 信号 | 触发次数 | 占比 | 类型 |
|:---|---:|:---:|---|
| **E2 量缩** | **89** | **38%** | 防守卖出 |
| **E3 趋势反转** | **80** | **34%** | 防守卖出 |
| **E4 评分骤降** | **58** | **25%** | 防守卖出 |
| E1 RSI衰减 | 3 | 1% | 防守卖出 |
| **P3 1h趋势衰竭** | **2** | **1%** | **主动止盈** |
| **P1 RSI>80** | **0** | **0%** | **主动止盈** |
| E5/E6 | 0 | 0% | 未触发 |

### 核心发现

**1. E3是头号亏损源（34%），其次E2（38%）**
这两个合计占72%的卖出。但E2更多是自然成交量萎缩（说明买完后没人跟了），E3才是趋势真正反转的信号。

**2. 主动止盈(P1/P3)几乎从未触发**
- P1 (RSI>80止盈): **0次触发** — 这意味着买入后RSI从未涨到80以上
- P3 (1h趋势衰减): **2次触发** — ACH和ORDI
- 这2次P3触发都在亏损状态下（ORDI -4.6%，ACH略亏）

**3. 整个系统只有"止损"没有"止盈"**
系统设计逻辑：全是条件满足就卖出（坏了就卖），没有"涨够了就卖"。唯一的止盈信号（P1 RSI>80）从未触发过，因为系统买在RSI中段（平均51.6），趋势还没来得及涨到RSI>80就反转了。

**4. 05-03单日E3占比高达40%**
```
05-03: E3=27次, E2=18次, E4=21次
```
E3在加速恶化——系统买入的币趋势反转越来越快。

### 退出后价格验证（卖出后价格是否真跌了？）

抽样验证（根据node_history，E3卖出后价格走向）：
- ACH被P3卖出后，下个节点USDT无持仓变化
- DOGE被E3卖出后，后续节点未再见到DOGE直到下次买入
- 实际验证困难因为node_history只有Top5评分和不全的持仓

但逻辑验证：E3触发条件（trend<0）意味着当前价格已低于EMA7和EMA25，卖在下跌途中是合理的。问题不在E3卖错了，**问题在E3卖的时候已经亏了**。

## 六、老李的核心问题回答

### Q: 从445U到414U（-31U/-7%），是策略问题，市场问题，还是执行偏差？

**答案：100%策略问题。不是市场环境，不是执行偏差。**

证据：
1. **市场环境不是问题** — 同期BTC/ETH没有剧烈波动，BinanceTop50成交额正常。大盘不背锅。
2. **执行偏差不是问题** — 所有交易都通过API成功执行，滑点控制合理（市价单买卖差约0.1%）。
3. **策略模型有系统性问题** — 详见下方根因分析。

### Q: 如果是策略问题——数据不够、模型不对、参数不合理？

**三者都有，但根因是模型不对。**

| 维度 | 判定 | 证据 |
|:---|---:|:---|
| **数据不够** | ⚠️ 部分成立 | 没有多时间框架数据(只有30minK线)/无资金费率/无链上/无盘口深度 |
| **模型不对** | ✅ **根因** | 入场趋势条件trend>=0允许买在趋势末端；没有趋势年龄/寿命判断 |
| **参数不合理** | ✅ 严重 | 量比>=1.0太松(应>=1.5)；E3 treen<0即卖(应加缓冲期) |

### 根因链条

```
6AND条件「trend >= 0」
  → 允许买在trend=1/2的币（已经涨了一截）
  → 上一轮trend也是正的，意味着已经涨了多轮  
  → 趋势自然衰减到-1/-2（下一节点或下下节点）
  → E3正确检测到趋势反转 → 卖出
  → 卖出时价＜买入价 → 亏损
  → 亏损平均-1% ~ -5%
  → 胜率32%补不回来
```

**核心矛盾：入场信号与趋势反转频率不匹配。** 系统试图捕捉30分钟级别的趋势，但趋势的平均寿命本身只有1-2个节点。当买入决策基于trend>=0，而trend的Life Time只有30-90分钟时，必然会买在多数的趋势末期。

### 修复方向

| 优先级 | 修复项 | 预期效果 | 改动量 |
|:---:|:---|---:|:---:|
| P0 | 买入trend条件改为「trend刚从平转升」 | E3减少40-50% | 2行 |
| P0 | 量比>=1.0提升到>=1.5 | 减少假放量 | 1行 |
| P1 | 连续退出冷却（同一币3次E卖后黑名单） | 停止DOGE每天买4次 | 5行 |
| P1 | E3加阈值缓冲：trend<=-1才卖，trend=0不卖 | 给趋势一个节点确认 | 2行 |
| P2 | 趋势年龄扣分：trend持续>=3节点扣10分 | 避免买在尾部 | 5行 |
| P2 | 接入资金费率为买入过滤 | 负费率不买 | 已接API |
