资金分配与交易品种 — 分阶段推进

为什么不能一步到位
$280做股票不现实
美股 Tesla 一股 $250，一张期权最低几百美元。API开户需要SSN或境外券商账户。 $280在股市等于没有。必须先在加密货币赚到 $5,000+ 再开股票。
竞猜平台无法自动化
Polymarket 是链上操作，没有公开交易API，只能手动。 可以作为手动副线（你已有经验），但不能纳入Hermes自动交易。
合约杠杆 = 加倍的风险
$280做10x杠杆，一个-5%波动就爆仓归零。 必须先在现货证明策略能赚钱（连续30天正期望值），再上合约。 合约是放大器，好策略放大，坏策略也放大。

你还没说清楚的 — 我来补充

7个你没提到但必须有的方面
① 数据基础设施 — 你的"全球分析"数据从哪来？
你说要分析全球经济、政治、政策、基金动向、500强 — 这些数据从哪来？
需要：宏观经济数据API（GDP/CPI/利率）、新闻API、基金持仓公开数据、链上数据、社交媒体情绪。
现状： 只有 CoinGecko + F&G指数。远远不够。需要接入更多数据源。
② 合规与税务 — 多交易所、多品种的合规
币安、火币、欧易在不同国家有不同的监管要求。
股票交易需要券商账户（嘉信、盈透、富途等），需要身份认证。
竞猜平台在某些地区可能不合法。
交易盈利的税务申报 — 不申报 = 违法。
现状： 未涉及。需要在扩大规模前处理。
③ 安全体系 — API密钥和资金安全
3个交易所的API密钥、AWS SSH密钥、钱包私钥 — 这些是整个系统的命脉。
规则：API只开读取+交易权限，禁止提现权限。
推荐：绑定服务器IP白名单。
备份：所有密钥加密备份，不在代码中硬编码。
现状： 已在遵循（API无提现权限），但密钥管理可以更规范。
④ 竞争优势 — 你的"边"在哪里？
市场上有无数交易者、分析师、内容创作者。你凭什么赢？
可能的"边"：
- 速度边：AI+自动化比人快，5分钟扫描20个币
- 纪律边：机器没有恐惧和贪婪，严格止损
- 数据边：积累自己的交易数据库，别人没有
- 内容边：用真实交易记录做内容，不是空谈
关键洞察：你的边 = 自动化 + 真实交易记录 + AI分析。不要跟人比手动分析，你赢不了华尔街分析师。
⑤ 内容变现路径 — 不只是分享
分享经济走向不能直接赚钱，需要变现路径：
1. 积累粉丝 → 付费社群（知识星球/Discord）
2. 交易策略课程 → 售卖
3. 付费研报 → 订阅制
4. 带单分润 → 跟单平台
前期（0-3个月）只做免费内容积累粉丝，不急于变现。
⑥ 团队 vs 个人 — 一个人能做多大？
前期完全个人 + AI。AI就是你的团队。
当资金到 $20K+ 时，考虑：
- 虚拟助手处理日常内容发布
- 会计师处理税务
- 技术顾问（如果代码维护跟不上）
原则：能用AI做的不雇人，能自动化的不手动。
⑦ 失败预案 — 如果亏完了怎么办？
$280全部亏损的可能性是存在的。需要预案：
1. 设置硬性回撤线：总资金回撤到 $200 时暂停交易，复盘
2. 永远不留全部资金在交易所 — 留 $50 在冷钱包作为"重启资金"
3. 如果策略连续30天亏损 → 停止，不是加仓
原则：能输得起才玩得起。$280是学费，不是身家。

风控体系 — 系统的免疫系统

层级 规则 触发条件 动作
L1 单笔 单笔风险 ≤ 2% 每笔交易前检查 超过则拒绝开仓
L2 止损 F&G联动止损 持仓浮亏达止损线 立即市价平仓
L3 集中度 单币 ≤ 30% 开仓前检查 超过则减少仓位
L4 并发 最多3个同时持仓 开仓前检查 满仓则不开新仓
L5 熔断 连续5亏 或 日回撤3% 每日复盘检查 暂停交易1天 + 人工复查
L6 总回撤 总回撤 ≥ 8% 实时监控 停止所有交易 + 全面复盘
L7 底线 总资金 < $200 每次交易后检查 提取$50到冷钱包 + 暂停
