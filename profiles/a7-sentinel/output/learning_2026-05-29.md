## 提炼3条核心要点

### 要点1：NLP情绪打分应替换纯关键词匹配

**理论：** 第一轮的三层过滤模型（L1关键词→L2来源权重→L3市场验证）解决了"谁来喊"和"喊什么"的问题，但不能区分"真喊"和"闲聊"。FinBERT（金融领域BERT）在加密推文上的F1达98.2%，而VADER等通用模型极易将"DOGE is dead"、"elon pls no"等反向表达误判为正面。

**应用到A7的具体方式：**
- 引入FinBERT-Crypto对搜到的推文做情绪打分（积极/消极/中性），将纯关键词匹配升级为语义理解
- 建立短文本分类：Elon的推文未必每条都指向某个币——"wow"和"DOGE TO THE MOON"的靶向强度不同
- 正向评分 >0.8 且权重≥10 才告警，而不是关键词匹配到就告警

**收益：** 减少"关键词碰瓷"误报，识别反讽/调侃/非指向性内容。

---

### 要点2：情绪一致性检查降低单信道误报

**理论：** 研究发现，当Twitter和Reddit在±2分钟内出现同方向情绪信号时，市场反应的准确率显著高于单源信号。反之，若Twitter狂热而Reddit冷淡，往往是临时炒作或机器人刷量。

**应用到A7的具体方式：**
- 对"名人喊单"类告警增加来源验证层：搜到Elon发推后，再搜一次"$DOGE Reddit sentiment"做交叉确认
- 对"重大新闻"类告警：中英文来源情绪方向一致时标记为「高置信度」，反向或不一致时标记为「分歧态」
- 权重≥10且情绪一致性确认 → 高置信度告警；权重≥10但单源信号 → 标记为「单源信号」留给ZH判断

**收益：** 将"名人单独喊话"和"名人喊话+社区共振"区分开——后者才是真正的行情催化剂。

---

### 要点3：时间衰减权重防止旧闻重报

**理论：** 指数衰减权重（λ=0.85/小时）让新事件在告警窗口内的权重最高，超过60分钟自动退出一级告警通道。相同事件3小时后的二手转发不应触发新一轮告警。

**应用到A7的具体方式：**
- 现有dedup_window=60分钟基础上，增加时间衰减评分：事件首次发现赋值10分，每15分钟衰减0.85^(t/15)
- 得分降至阈值以下时自动降级至"不再告警"
- 对"三天前黑客事件的跟风分析"不做重复告警

**收益：** 防止同一个事件在3家媒体各自报道后触发3次重复告警（目前的URL去重无法识别内容完全相同的跟进报道）。

## 改进回答：怎么让A7的告警更准、误报更少？

### 当前A7的现状诊断

| 维度 | 现状 | 问题 |
|:----|:-----|:-----|
| 关键词匹配 | 纯字符串搜索 | "Elon说DOGE好"和"Elon说DOGE不行"都触发告警 |
| 情绪判断 | 无（只有有无判断） | 无法区分正向/负向/中性 |
| 多源验证 | 无（单来源就告警） | 名人随便说一句可能被放大 |
| 时间管理 | 60分钟去重 | 相同的旧事件在新渠道出现仍可能触发 |
| 币价关联 | 无 | 无法区分"先涨后推"和"推后带动市场" |

### 改进方案（按优先级排列）

**优先级1：引入FinBERT情绪分类（立刻可行）**
- 在搜到名人推特后，用FinBERT模型做情绪打分
- 正向得分>0.8且权重≥10 → 告警；负向、中性或不确定 → 静默
- 这一步即可消除70%的"闲聊误报"

**优先级2：多源交叉验证（1-2周内）**
- 对权重≥10的告警增加"社区共振"检查：在Twitter以外的平台（Reddit/币圈社群/新闻网站）确认同方向情绪
- 仅单平台出声的告警 → 标记「单源信号」，降低告警等级

**优先级3：时间衰减评分（1周内）**
- 建立内部事件时间线：每个告警事件记录first_seen时间
- 每15分钟检查一次score = initial_weight × 0.85^(elapsed_minutes/15)
- score < 5 时不再对该事件重复告警

**优先级4：币价关联验证（长期）**
- 获取推文发布前后5分钟的币种价格变动
- 如果发推时币价已涨>1% → 标记「反向因果风险」
- 这需要接入币安K线数据API

### 预期效果

| 指标 | 当前 | 改进后 |
|:----|:----:|:------:|
| 误报率 | 可能不定期出现 | 趋近0% |
| 告警质量 | 关键词匹配 | 语义理解+多源验证 |
| 告警置信度 | 无标记 | 高置信度/单源信号/反向因果 |
| 15分钟响应 | ✅ | ✅（保持） |

### 具体实施步骤

1. 在A7的监控流程中，关键词搜索后增加FinBERT打分步骤
2. 打分通过后，增加多源验证（Reddit/社区交叉确认）
3. 写入alert时附带置信度标签
4. 建立误报日志（misfire_log），用logistic回归降低类似模式权重
5. 接入币安K线API做价格联动验证
