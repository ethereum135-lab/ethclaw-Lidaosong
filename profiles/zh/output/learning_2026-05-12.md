## 策略一：RSI均值回归

### 核心原理

RSI（相对强弱指数）= 100 - (100 / (1 + RS))，其中 RS = 过去N日平均涨幅/平均跌幅。

**关键洞察：** 在震荡市场中，极端RSI值（<25或>75）倾向于回归均值（~50）。这不是玄学——它是统计学上的"买在恐慌，卖在狂热"的量化表达。

### 参数优化

| 参数 | 传统值 | Crypto适配 | 原因 |
|:-----|:------:|:-----------:|:-----|
| RSI周期 | 14 | **21** | Crypto噪音大，长周期过滤假信号 |
| 超卖阈值 | 30 | **20-25** | 避免在强趋势中逆势抄底 |
| 超买阈值 | 70 | **75-80** | Crypto波动大，给更多空间 |
| 时间框架 | 日线 | **4H/1D** | 30分钟线噪音太大，不适合A4每30分钟执行 |

### 入场/出场规则（现货做多）

```
入场信号（三条件同时满足）：
① RSI(21) < 25 刚形成（最近一次从超卖区域返回）
② 价格站上最近5根K线低点（确认底部形成）
③ 成交量比前5根平均高出至少20%（量价配合）

出场规则：
目标1: RSI回到50（均值），出场50%仓位
目标2: RSI(21) > 70 或 价格触及阻力位（收益保护）
止损: RSI继续跌破20 或 价格跌破最近低点的2%
```

### 失败的四种模式

1. **强趋势中逆势** — RSI在趋势中会长期超买/超卖。ADX>25时禁用此策略
2. **缺口/闪崩** — 价格一步到位越过止损，无法执行风控
3. **抄底到半山腰** — 下跌趋势中RSI一再跌破新低
4. **成交量太小** — 流动性不足导致无法按计划建仓/出场

### Crypto特有的适配

- 必须是**有深水合约的币**（流动性好），否则闪崩止损无效
- 回避稳定币锚定的山寨（USDT计价的极端行情会断线）
- 大市值币（BTC/ETH）的RSI均值回归更可靠，但幅度小
- 中市值币（$100M-$1B）的均值回归幅度大，但噪音也大

### 性能预估

| 市场环境 | 胜率 | 盈亏比 | 适用？ |
|:---------|:----:|:------:|:------:|
| 横盘震荡(ADX<20) | 60-70% | 1.5-2.0 | ✅ 最佳 |
| 弱趋势(ADX 20-25) | 50-55% | 1.0-1.5 | ⚠️ 谨慎 |
| 强趋势(ADX>25) | 30-40% | 0.5-1.0 | ❌ 禁用 |
| 高波动(ATR>20日均值2x) | 40-50% | 1.0-1.3 | ⚠️ 缩仓位 |

## 策略二：布林带均值回归

### 核心原理

布林带：中轨 = SMA(20)，上下轨 = SMA ± k·σ。在平稳市场中，价格从下轨回归中轨的概率很高。

**关键参数选择：**
- N=20（传统），Crypto用N=40（过滤噪音）
- k=2.5-3.0（传统2.0在Crypto中假信号太多）
- 布林带宽度（BBW）= (上轨-下轨)/中轨 → **BBW收缩时均值回归效率最高**

### 入场/出场规则

```
入场信号：
① 价格触及或收盘低于下轨（k=3.0）
② 出现反转K线形态（锤子线/看涨吞没）——不需要精确识别，只要该K线实体>前3根平均的1.5倍且收阳
③ 布林带宽度处于历史30%分位以下（收窄=蓄力）

出场规则：
第一目标: 中轨（SMA），出场60%仓位
第二目标: 上轨（如果趋势延续），出场40%仓位
止损: 价格收盘低于下轨超过1%
```

### 布林带 + RSI 双重确认（推荐组合）

这个组合是最实用的——两个信号独立但互补：

```
当 RSI(21) < 25 AND 价格 < 下轨(k=3.0) 同时成立：
  → 信号强度 × 2
  → 建仓量从5%提高到10%
  
当两个信号只有1个成立：
  → 正常建仓（5%）
  → 设置更紧的止损（-3%而不是-5%）
```

### 布林带宽度（BBW）的预测价值

| BBW状态 | 含义 | 操作 |
|:--------|:-----|:-----|
| 极窄（历史最低20%）| 即将爆发（方向待定） | 进入预警，不建仓 |
| 收缩（从高位回落）| 波动率下降，均值回归概率增加 | ✅ 正常执行均值回归 |
| 扩张（快速扩大）| 趋势突破，波动率上升 | ❌ 禁用均值回归，考虑趋势策略 |
| 极高（历史最高20%）| 极端行情 | ❌ 不交易，等待回归 |

## 策略三：配对交易（协整方法）

### 核心原理（关键理解）

配对交易找的是两个币的**价差**（不是价格）的均值回归。如果X和Y存在协整关系，即 Y - βX = 残差(平稳)，那么当价差偏离均值时，预期它回归。

### ⚠️ 现货限制：Crypto不可行

**致命问题：** 配对交易需要做多一个 + 做空另一个。现货只能做多。

**Crypto现货的四种变通尝试（全部有缺陷）：**

| 变通方式 | 问题 | 结论 |
|:---------|:-----|:----:|
| 同时做多价差中的"便宜"币 | 如果两个币都跌，一样亏钱 | ❌ 无对冲效果 |
| 用永续合约做空 | ZQ系统不用合约 | ❌ 不在范围 |
| 只做"双涨"行情中的配对 | 需要判断市场方向，配对的意义减半 | ❌ 没必要用配对 |
| 用看跌期权代替做空 | 流动性极差，Crypto期权成本高 | ❌ 不现实 |

**结论：配对交易在纯现货系统中无法真正实现。** 先记着，等系统支持合约或增加资金到$500+后再考虑。

## 策略四：统计套利（简易版）

### 核心原理

把配对交易扩展到一篮子币（10-30个）。用PCA（主成分分析）提取市场共同因子（BTC因子、ETH因子、板块因子等），然后看每个币的**残差**——被因子没解释的部分——是否均值回归。

### 对ZQ系统的简化方案

```
每日计算（A2候选池里的10-30个币）：
1. 取过去30天的日收益率
2. PCA提取3-5个主成分
3. 每个币的"异质波动" = 实际收益率 - PCA预测的收益率
4. 异质波动 > 2σ → 该币被市场"错杀" → 买入
5. 异质波动 < -2σ → 该币被"高估" → 不卖（不能做空）
```

### 对系统的价值

统计套利的残差分析可以给A3的"量价结构"打分增加一个维度：
- 目前A3的90分量价结构评分：只看了成交量和趋势
- 如果加上"异质波动"维度：被市场错杀/错爱的币 → 更精确的判断

## 核心认知升级

### 今天学到的最重要的一件事

**均值回归和趋势跟踪不是"哪个更好"的关系——它们是互补的两种生存策略。** 在震荡市做趋势跟踪必亏（旧引擎就是例子），在趋势市做均值回归同样必亏。

一套成熟的交易系统必须**同时具备**这两种策略，并根据市场阶段自动切换。

### 对系统架构的启示

```
当前ZQ系统：一套策略（类似趋势跟踪）应对所有市场
    ↓ 升级方向
ZQ未来系统：
  if 市场阶段 == 趋势:
      使用趋势策略（A3的动量维度权重提高）
  elif 市场阶段 == 震荡:
      使用均值回归策略（A3的RSI+BB维度权重提高）
  elif 市场阶段 == 高波动:
      减仓/空仓（仅执行止损）
```

### 为什么旧引擎亏钱

旧引擎（engine_realtime_v2.py）的核心逻辑：
- E2出场：趋势转负就卖 → 在震荡市中频繁止损
- E3出场：亏损持续扩大 → 平均-5.9%/笔
- 没有市场阶段判断 → 不管什么市场都用同一套参数

**根因：** 不是某个参数不对，是**策略与市场不匹配**的问题。在横盘震荡市中跑趋势跟踪策略，神仙来了也亏钱。
