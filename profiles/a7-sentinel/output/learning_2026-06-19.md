## 3条核心要点

### 要点一：从Granger因果到结构因果模型——推文→价格的因果推理升级

**理论背景：**
C2的学习聚焦于Granger因果检验（统计级的时间领先关系），C4需要升级到**结构因果模型（SCM）**。Granger因果的本质是"时序预测性"——如果X的历史能提升Y的预测精度，则X Granger-cause Y。但这不回答反事实问题："如果KOL没发那条推，价格会怎样？"

**最新研究成果：**
1. **TNCM-VAE（Time-series Neural Causal Model VAE, arXiv 2511.04469）**：将变分自编码器与结构因果模型结合，生成金融市场反事实场景。可用于模拟"去除Elon的推文后，DOGE价格走势"的因果效应。
2. **对称性感知Transformer（MDPI Symmetry 2025）**：利用金融时间序列的不对称因果结构，捕获KOL推文→价格的单向传导（推文先于价格→高因果效应；价格先于推文→补推标记）。
3. **CausalNLP研究路线图（GitHub zhijing-jin/CausalNLP_Papers）**：建立因果NLP文献体系，涵盖因果关系抽取、反事实文本生成、do-算子在NLP中的应用。

**对A7的具体应用：**
- 建立**因果效应评分**代替当前基于权重乘法的告警规则：`Causal_Effect = P(price_moves | do(Tweet)) - P(price_moves | no_tweet)`
- 利用TNCM-VAE框架，对每条告警KOL推文计算**反事实价格差**（counterfactual price delta），量化推文的真实市场驱动力
- 实施步骤：收集推文前后15分钟K线数据 → 构建因果图（KOL推文→社区情绪→交易量→价格） → 用do-calculus计算每条推文的平均因果效应（ACE）

### 要点二：KOL行为马尔可夫建模——用隐马尔可夫模型（HMM）捕捉KOL行为状态转换

**理论背景：**
KOL的推文行为不是随机的——它遵循一个隐含的状态序列。如Elon在"积极推广模式"→"沉默模式"→"回应粉丝模式"之间切换。识别当前所处的状态，比单条推文分析更具预测力。

**最新研究成果：**
1. **HMM市场体制检测（Mathematics 2025, MDPI）**：Bitcoin价格行为在高sentiment灵敏度、低流动性、高波动的体制间切换。HMM能检测这些隐状态。
2. **马尔可夫链社交采用模型（IJSRST 2025）**：提出KOL引导采用的马尔可夫链模型，参数包括`θ`（同行影响采用率）和`γ`（事件触发退出率）。
3. **HMM+社交媒体情绪（Borçka SCIENCE@home）**：加密货币市场行为存在未观测的异质性，HMM能捕捉情绪驱动下的市场状态转移。

**对A7的具体应用：**
- 为每个监控的KOL建立**3态HMM**：
  - **状态0（静默）**：24h内无相关推文
  - **状态1（信息分享）**：发布一般性内容/转发，无明确喊单
  - **状态2（活跃推广）**：靶向喊单、价格预测、明确的买入/卖出信号
- 状态转移矩阵`P`反映KOL的历史行为模式：
  ```python
  # 示例：Elon的状态转移矩阵（估计）
  P_elon = [[0.7, 0.2, 0.1],   # 静默→各状态
            [0.3, 0.5, 0.2],   # 信息→各状态
            [0.1, 0.3, 0.6]]   # 推广→各状态
  ```
- 当KOL从静默状态（0）跃迁到推广状态（2）时，**告警权重×3**——这种状态转换的历史价格影响最大
- 结合发射概率（observations = 推文关键词强度、情感分数、转发量）做实时状态估计

### 要点三：SIR-like群体情绪传播模型——将KOL情绪传染视为流行病

**理论背景：**
KOL推文引发的市场反应本质上是情绪通过社交网络传染的流行病学过程。SIR（Susceptible-Infected-Recovered）模型为理解这一传播过程提供了数学框架。

**最新研究成果：**
1. **达拉斯联储研究论文（2026年WP2605）**：首次提供**微观层面的直接证据**证明Bitcoin市场中投资者情绪通过社交互动传播。使用社交互动和个人交易记录新数据，发现投资者显著地将其Bitcoin信念更新为与同行平均情绪相同的方向。
2. **SIR模型应用于Crypto崩溃（Springer 2024）**：首次将SIR模型应用于加密货币平台崩溃评估。用互联网搜索流量索引估计感染率参数。
3. **时间延迟SIR+博弈论（Annals of Operations Research 2025）**：用带有时间延迟的SIR微分方程系统描述crypto交易所之间的风险传染，结合复制动力学方程寻找合作策略。
4. **Bitcoin感染病模型（Emerald 2024）**：将Bitcoin钱包分为S（可感染——未激活钱包）、I（感染——活跃交易钱包）、R（康复——已退出钱包）。

**对A7的具体应用：**
- 为每个KOL影响力事件建立**SIR模型参数估计**：
  ```
  dS/dt = -β·S·I/N    # 易感染者的减少 = 传播率 × 感染者接触
  dI/dt = β·S·I/N - γ·I  # 感染者的变化 = 新感染 - 康复
  dR/dt = γ·I           # 康复者 = 退出关注
  ```
  - **β（传播率）** ≈ KOL推文的转发率/互动率——值越高说明情绪传播越快
  - **γ（康复率）** ≈ 推文发布后到市场反应消退的时间倒数——值越高说明消退越快
  - **R₀（基本再生数）** = β/γ —— >1意味着推文能引发持续的市场关注，<1意味着影响迅速消退

- **实施步骤**：
  1. 检测到KOL推文后，采集该币种社交媒体互动率（转发、浏览量）作为`β`的代理
  2. 采集价格波动消退时间（从peak回归到baseline的时间）作为`1/γ`的代理
  3. 计算R₀：若R₀>1.5 → 标记`[高传播风险]`，表示情绪可能持续扩散
  4. 若R₀>2.0且β>阈值 → 写入alert（社区共振强传播风险）

- **与A7现有体系的融合**：
  - 将SIR模型输出作为社区共振判断的定量基础
  - 高R₀ = 社区共振:强，中等R₀ = 社区共振:中，R₀<1 = 社区共振:弱（单源信号）
  - 替代当前基于web_search关键词匹配的粗略共振判断
