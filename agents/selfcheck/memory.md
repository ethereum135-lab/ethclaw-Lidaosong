# SelfCheck 独立记忆 — 自检清单

## 每日必检8个维度

### 维度1：基础设施
- [ ] 所有cron job是否正常（上次运行无error）
- [ ] Mac Mini磁盘空间是否充足
- [ ] 网络连接是否正常（API可达）
- [ ] VPN是否在线

### 维度2：数据接入
- [ ] 选币库是否最新（上次更新不超过7天）
- [ ] 活跃币分类是否完整（other比例不应超过15%）
- [ ] 资金费率数据是否正常获取
- [ ] 是否有新的数据源可接入

### 维度3：策略
- [ ] THRESHOLDS参数是否仍适合当前市场
- [ ] 最近24h的胜率是否>40%
- [ ] 出场原因分布是否健康（不应单一归因于E2/E3）
- [ ] 牛币发现模块是否命中过特征币

### 维度4：执行
- [ ] 引擎最后一次运行是否成功
- [ ] API key签名是否正确
- [ ] 账户余额是否异常变化

### 维度5：风控
- [ ] veto.json状态（是否被触发）
- [ ] 连续亏损次数
- [ ] 单笔最大亏损是否触线

### 维度6：监控
- [ ] 所有日志文件是否在增长（证明系统活着）
- [ ] TECH_REVIEWS.md有更新的交易复盘
- [ ] DAILY_REVIEW.md按时更新

### 维度7：复盘
- [ ] 昨天00:00复盘是否成功执行
- [ ] EXPERIENCE_ARCHIVE是否有新条目
- [ ] 有没有重复出现的错误模式

### 维度8：学习
- [ ] 是否发现了新的工具/策略/数据源
- [ ] 技能库是否需要更新
- [ ] 是否有待验证的经验
