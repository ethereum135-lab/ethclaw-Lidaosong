### 对A8的改进建议

**实装方案（放入a8_data_fetch.py步骤11）：** 每次采集时curl DeFiLlama `/protocol/aave-v3`，提取Ethereum TVL+borrowed时序的最后2个采样点，计算当前Utilization和24h变化。

```python
def fetch_aave_utilization():
    """采集Aave V3借贷Utilization率"""
    url = "https://api.llama.fi/protocol/aave-v3"
    resp = requests.get(url, timeout=15)
    data = resp.json()
    ct = data['chainTvls']
    eth_tvl = ct['Ethereum']['tvl'][-1]['totalLiquidityUSD']
    eth_borrowed = ct['Ethereum-borrowed']['tvl'][-1]['totalLiquidityUSD']
    utilization = eth_borrowed / eth_tvl * 100
    # 24h前数据点
    prev_idx = -2  # 大致的24h前
    prev_util = ct['Ethereum-borrowed']['tvl'][prev_idx]['totalLiquidityUSD'] / \
                ct['Ethereum']['tvl'][prev_idx]['totalLiquidityUSD'] * 100
    return {
        'tvl_usd': eth_tvl,
        'borrowed_usd': eth_borrowed,
        'utilization_pct': round(utilization, 1),
        'utilization_24h_delta': round(utilization - prev_util, 1)
    }
```

**信号触发条件：**
- Utilization > 80% + 24h上升 > 3% → 🔴 借贷过热(加杠杆信号)
- Utilization上升 > 5%/24h → 🟢 资金准备入场(提前3-6h预警)
- Utilization下降 > 5%/24h → 🔵 去杠杆(做多信号降级)

## 要点三：时序拐点检测 — 从「单点值」升级为「趋势+加速度」

当前A8的L5层（借贷Utilization监控）只采集单点TVL。本轮学习引入**三体系时序检测**，利用已采集的时序数据发现「大钱在路上了」的早期信号。

### 三体系时序检测框架

| 体系 | 检测方法 | 信号含义 | 领先时间 |
|:-----|:---------|:---------|:--------:|
| **体系统：Utilization趋势** | 比较最近2个采样点 vs 7天均值 | 借贷需求正在加/减速 | 3-6h |
| **体系二：TVL增速拐点** | 7天TVL变化率的二阶导数 | 新资金是否加速涌入/逃离 | 6-12h |
| **体系三：净流入量** | TVL增量 - 价格影响 | 实际新资金数（剔除价格变量） | 6-24h |

### 体系统一的计算方法（Python模板）

```python
def detect_inflection(points_7d: list) -> dict:
    """
    对7天TVL时序做拐点检测
    返回: {'velocity': 趋势方向, 'acceleration': 加速度, 'inflection': 拐点时间}
    """
    import numpy as np
    if len(points_7d) < 4:
        return {'velocity': 'insufficient_data'}
    vals = np.array([p['totalLiquidityUSD'] for p in points_7d])
    # 一阶差分（速度）
    velocity = np.diff(vals) / vals[:-1] * 100  # 每日变化率%
    # 二阶差分（加速度）
    acceleration = np.diff(velocity)
    return {
        'velocity_pct_mean': round(float(np.mean(velocity)), 2),
        'velocity_trend': 'accelerating' if len(acceleration) > 0 and acceleration[-1] > 0 else 'decelerating',
        'last_24h_change': round(float(velocity[-1]), 2) if len(velocity) > 0 else None,
        'inflection_detected': any(abs(a) > 3 for a in acceleration[-3:]) if len(acceleration) >= 3 else False
    }
```
