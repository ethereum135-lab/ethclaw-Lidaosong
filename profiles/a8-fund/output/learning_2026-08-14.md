## 🔑 要点一（更准）：稳定币流≠买入信号 — 「干火药 vs 避险避难所」双解必须区分

### 发现：同一个数据，两种相反解读（Neutralis × Miners1688 × Cryptonomist 三源对照）

AnySearch命中三篇2026年实证/实践研究，对「稳定币流入」给出**完全相反**的解读——这正是当前A8把MONEY_IN一刀切报「买入信号」的隐患：

| 来源 | 解读方向 | 证据 |
|:-----|:--------|:-----|
| **Miners1688**（2026-01实证） | 🟢 **干火药** | 稳定币供应增长=新资本进入生态=「dry powder」最终流入BTC/alt推高价格。USDT+USDC在2026年1月中旬引领周度流入，市场流动性空前 |
| **Cryptonomist/Mercuryo**（H1 2026实证） | 🔴 **避险避难所** | H1 2026加密总市值跌30%($2.96T→$2.08T)，风险偏好下降时资金**几乎全部**逃向USDT/USDC——稳定币吸收的是恐慌，不是进攻 |
| **Neutralis**（2025-2026对冲基金实践） | ⚪ **中性/噪音** | 单笔稳定币转账可能是treasury再平衡、套利、链迁移、托管商切换——**不含风险偏好信息**。全球稳定币市值2026年初已超**$230B**（DeFiLlama），接近2023末的两倍 |

**三源共识：** 稳定币供应增长方向本身不构成买卖信号——必须结合「谁在铸造/谁在流入/市场处于什么位置」三重上下文。

### 对A8的改造方案

A8当前MONEY_IN格式 `ETH|USDT|1000000|in|0x...` 只有金额+方向+地址前缀，无法区分场景。改造为三类标签（全部复用已有Etherscan数据+地址标签，零新API）：

```python
# MONEY_IN 新增 scene 字段（复用已有地址标签 + Tether Treasury识别）
def classify_stablecoin_scene(tx, market_state):
    """三场景区分：干火药/避险/中性"""
    if is_tether_treasury(tx['from']):
        return 'dry_powder'      # 净铸造>销毁 = 新流动性创造 → 升权（供应端）
    if tx['to'] in EXCHANGE_ADDDRESSES and market_state['risk_on']:
        return 'dry_powder'      # 风险偏好高时入交易所 = 准备买入 → 升权
    if tx['to'] in EXCHANGE_ADDDRESSES and not market_state['risk_on']:
        return 'flight_to_safety'  # 避险期入交易所 = 卖出待命 → 中性偏空
    return 'neutral'             # 钱包间/再平衡 → 维持低权重（Neutralis警示）
```

**市场状态代理（risk_on判定，无需新API）：** BTC价格相对30日均线位置 + 稳定币净流入交易所方向——价格在均线上方且净流入=risk_on；价格在均线下方=risk_off。

### 📌 要点一结论
> 三源对照证明：**稳定币流入的方向性解读必须依赖市场状态**。A8当前把全部>$500K稳定币转账报为「资金流入」≈ 30%以上概率误读（Cryptonomist实证：risk-off时稳定币吸收的是恐慌）。引入`scene`标签后，同一笔转账在牛市=干火药（升权），在熊市=避险（降权），信号精度显著提升。

## 🔑 要点二（更快）：稳定币流领先价格15-30分钟 — 信号新鲜度窗口有了定量校准

### 发现：Neutralis给出领先时间窗的定量答案

Neutralis基于2025-2026年对冲基金实战观察：**稳定币流通常携带15-30分钟的领先滞后关系**（对目标资产价格）。Miners1688同样强调：理解「stablecoin velocity（流通速度）和lead-lag关系」是使用该指标的核心。

这直接回答了A8的一个悬而未决的问题：**稳定币信号多久失效？**

```
稳定币转账发生 (T0)
    ↓ 15-30分钟领先窗口
价格开始反应 (T0+15~30min)
    ↓
超过30分钟 → 信号已price-in，不再有额外信息价值
```

### 对A8的改造方案

1. **新鲜度窗口校准：** 把稳定币类信号（MONEY_IN）的freshness衰减窗口设为 **30分钟**（非通用的0-5min=10分/>4h=0分）——信号在15-30分钟窗口内有效，超过30分钟降为0分。这比当前「>4h仍有信息」的评分激进得多，**与稳定币领先窗口物理对齐**。

2. **扫描频率对齐：** A8当前15分钟扫描频率落在领先窗口内（15min < 15-30min），**频率本身已够快**——真正的瓶颈是「扫描到→判定→写JSON→A3读到」的管道延迟。要求整链延迟 < 10分钟（含SSH桥接），否则信号在A3读到前就已过窗口。

3. **优先队列：** 稳定币场景=干火药 且 最近30分钟内 → 直接写入`fast_signal`队列（A3优先读），不再混在MONEY_IN普通列表里按批处理。

### 📌 要点二结论
> Neutralis给稳定币信号贴上了「15-30分钟保质期」标签。A8只要把新鲜度窗口从「>4h还有效」校准为「30分钟作废」，并在快照中标记`freshness_until`字段，就能保证A3读到的稳定币信号永远是「未过期」的。**校准时间窗 = 零成本提速。**

## 🔑 要点三（更准）：Utilization的kink非线性 — 80%区的+2%比70%区的+5%信号强得多

```
利率
 ↑                          ╱ slope2 (kink区：陡升)
 │                     ╱
 │                ╱  ← optimal utilization (~70-80%，协议参数)
 │           ╱ slope1 (平缓区)
 └────────────────────────────→ Utilization
       0%    70-80%     100%
```

- **borrow demand把utilization推向100%时，利率kink急剧上升**，目的是保留提款流动性
