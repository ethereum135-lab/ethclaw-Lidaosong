## 一、麦语言（MyLanguage）— 文华财经策略脚本语言

### 核心概念
麦语言是文华财经(MY)自主研发的类C交易策略脚本语言，用于编写自动化交易策略。中文语法，面向国内期货/股票/加密货币交易者。

### 关键语法要素
```
// 典型策略结构
N1:=20;      // 参数定义
N2:=55;
MID:=MA(CLOSE,N1);   // 移动平均
UP:=MID + 2*STD(CLOSE,N1);    // 布林带上轨
DN:=MID - 2*STD(CLOSE,N1);    // 布林带下轨

// 开仓条件
BK: CROSS(CLOSE,UP) && VOL>MA(VOL,5)*1.5;  // 突破上轨+放量→买开
// 平仓条件
SP: CROSS(DN,CLOSE) || CLOSE<MID;           // 跌破下轨或中轨→卖平

// 止损
STOP: (HHV(H,ENTERBARS+1)-CLOSE)/REF(CLOSE,ENTERBARS)>0.02;  // 2%硬止损
```

### 对ZQ系统的启示
| 麦语言特点 | 对应ZQ系统 |
|:-----------|:-----------|
| 参数可优化(N1,N2) | A3的评分权重体系 |
| 多条件AND/OR | A4四查闸门逻辑 |
| 止损硬编码/软条件 | E1-E4退出体系 |
| 回溯测试引擎 | A5复盘+经验值 |

**核心借鉴：** 麦语言的"模型验证"理念——写策略必须能回溯测试。ZQ系统当前缺少完整的策略级回溯——每笔交易有复盘，但缺乏策略层面的胜率/盈亏比统计。**缺：策略回溯数据库**。

## 二、系统交易（System Trading）— 纪律核心

### 定义
系统交易 = 完全由预定义规则驱动的交易，不做主观判断。核心四要素缺一不可。

### 四要素框架

```
┌─────────────────────────────────────────────┐
│              系统交易四要素                    │
│                                              │
│  ① 入场规则 → 什么条件下开仓/加仓            │
│  ② 出场规则 → 什么条件下平仓/减仓            │
│  ③ 仓位管理 → 每次开多少（风险量化）          │
│  ④ 资金管理 → 总风险敞口控制                  │
└─────────────────────────────────────────────┘
```

### 对ZQ系统的映射

| 四要素 | ZQ当前实现 | 状态 | 建议改进 |
|:-------|:-----------|:----:|:---------|
| ①入场 | A2→A3评分链 + A4四查闸门 | ✅ | 需加赛道维度过滤 |
| ②出场 | E1(RSI)/E2(量)/E3(趋势)/E4(评分) | ✅ | 需加时间止损(T) |
| ③仓位 | 末位淘汰制(4→8) | ⚠️ | 缺金字塔加仓机制 |
| ④资金 | USDT>$15 + 30%单币上限 | ⚠️ | 缺总风险值R计算 |

**最大差距在③仓位管理：** 当前系统是"等分投入"(买入时固定仓位)，没有金字塔式渐进入场。这意味着当趋势启动时，系统无法在早期轻仓试探、确认后加码——错失趋势行情最大利润段。

## 三、金字塔建仓法 — 核心原理

### 正金字塔 vs 倒金字塔

```
正金字塔（正确：追趋势）
仓位递增: 1→2→3→4→5 单位（递减）
  第1层: 突破入场 5%资金
  第2层: 回调确认+1N 4%
  第3层: 趋势强化+1N 3%
  第4层: 加速+1N 2%
  第5层: 极限+1N 1%
总敞口 = 15%资金
平均成本更靠近底部

倒金字塔（错误：摊平亏损）
仓位递增: 1→1→1→1→1（等额在下跌时加仓）
越跌越加 → 成本被拉低但浮亏绝对值增大
→ 遇到单边下跌直接爆仓
```

### 金字塔的核心纪律

```
法则1: 只在盈利仓位上加仓（不是在亏损上摊平）
   - 第1层进场后，价格必须朝有利方向移动N%才能加第2层
   - 如果价格反向 → 止损出场，不加仓

法则2: 每层仓位递减（不是等额）
   - 第1层: X单位
   - 第2层: 0.8X单位
   - 第3层: 0.6X单位
   - 越往后风险越小

法则3: 总仓位有硬上限（不是无限加）
   - 最大4-5层
   - 总风险敞口不超过资金X%

法则4: 每层独立止盈止损
   - 第1层有第1层的止损（可紧）
   - 最顶层有最顶层的止损（可宽）
   - 某层被止损，不影响其他层
```

### 对ZQ系统的接入方案

**当前缺：** A4买入只有"四查通过→买入固定仓位"，没有分仓机制。

**接入方法：**
1. A3推荐时标注"建仓价区间→阶梯加仓价位"（如SUI $1.16第一层，$1.14第二层，$1.12第三层）
2. A4在每层触发时独立通过四查闸门
3. 每层仓位递减（如第一层50%目标仓，第二层30%，第三层20%）
4. 每层独立止损（如第一层-3%，第二层-5%，第三层-8%）
5. 只有当上一层盈利时才能触发下一层（不是向下加仓，是向上加仓）

**⚠️ 接入风险：** 需要在A4的SOUL中增加"金字塔模式"开关，由A3在推荐中开启/关闭。趋势行情开金字塔，震荡行情关金字塔。根因：A3当前推荐基于四维分析(吸筹/埋伏/R/R/赛道)，需加上"趋势类型"字段。

## 四、海龟交易法则 — 完整规则

### 背景（必须理解）
Richard Dennis用$5000赚到$8000万+，证明交易能力可教。核心：**规则 > 直觉**。

### 完整规则体系

```
┌────────────────────────────────────────────────────┐
│                   海龟交易系统                       │
├────────────────────────────────────────────────────┤
│  1. 入场规则                                        │
│     系统1: 20日唐奇安通道突破（灵敏）                 │
│     系统2: 55日唐奇安通道突破（稳健）                 │
│     同时设置两个系统，各自独立交易                     │
│                                                     │
│  2. 加仓规则                                        │
│     在入场价基础上，每上涨0.5N加仓1单位              │
│     最多加到4单位                                   │
│     N = ATR(20)（真实波幅）                         │
│                                                     │
│  3. 止损规则                                        │
│     所有单位的统一止损：入场价-2N                    │
│     止损不变——不随加仓后平均成本移动                  │
│                                                     │
│  4. 出场规则                                        │
│     系统1: 10日唐奇安通道突破反向出场                 │
│     系统2: 20日唐奇安通道突破反向出场                 │
│                                                     │
│  5. 仓位计算（核心！）                               │
│     1单位 = 账户的1% ÷ N ÷ 合约乘数                  │
│     例：账户$100,000, N=50, BTC合约乘数1             │
│     1单位 = $1000 ÷ 50 ÷ 1 = 20个BTC               │
│     4单位满仓 = 80个BTC = $400,000名义价值 ≈ 4x杠杆  │
└────────────────────────────────────────────────────┘
```

### 为什么海龟法则有效？

| 原理 | 说明 |
|:-----|:------|
| **趋势捕获** | 突破系统在趋势开始时就入场，吃完整段趋势 |
| **风险管理量化** | N=ATR，仓位和风险完全量化——知道每笔交易最多亏多少 |
| **金字塔效应** | 加仓在盈利方向，利润放大但不盲目 |
| **反人性** | 突破时追涨（散户不敢），止损在支撑位下方（散户不舍得） |
| **双系统并行** | 灵敏+稳健捕捉不同周期趋势 |

### 海龟法则的最大弱点

| 弱点 | 说明 | 如何应对 |
|:-----|:------|:---------|
| **震荡市亏损** | 没有趋势时，假突破频繁→连续小亏 | 加ADX过滤（ADX<20不开仓） |
| **回撤期长** | 趋势交易最大回撤可达30-50% | 资金管理控制总体风险 |
| **大N陷阱** | N变大的时候，仓位变小；N变小的时候，仓位变大→在波动小的时候重仓 | 用固定百分比替代N |
| **出场太慢** | 趋势反转后才出场，回吐大量利润 | 加移动止盈保护部分利润 |

### 对ZQ系统的接入方案

**当前系统与海龟的对比：**

| 维度 | 海龟 | ZQ系统 | 差距 |
|:-----|:-----|:-------|:----:|
| 入场 | 唐奇安通道突破 | A3四维评分+四查闸门 | 缺明确的突破信号机制 |
| 加仓 | 0.5N递增×4层 | 末位淘汰固定仓位 | 缺金字塔 |
| 止损 | 入场-2N，固定不移动 | E1-E4动态退出 | 有但位置不固定 |
| 出场 | 反向通道突破 | E1/E2/E3/E4综合 | 信号太多，有时矛盾 |
| 仓位计算 | 1%风险/N | USDT余额/4 | 缺风险量化 |
| 资金管理 | 1%每笔 | USDT>$15 | 简单，但有效 |

**最大差距：** ZQ系统缺乏**风险量化单位**。海龟用N(ATR)把波动率风险量化，ZQ只用固定USDT金额。这意味着系统不知道"这笔交易亏损的概率有多大"——同时开多个仓位的总风险敞口也不可知。

**具体接入方法：**

```
① 在A3精选报告中增加N值计算
   N = ATR(14) × 权重因子
   写入 profiles/a3-bull/output/{date}.md 的 R/R 分析部分

② A4执行时计算"等价仓位"
   1单位 = (USDT余额 × 风险比例(%)) ÷ N ÷ 当前价
   例: USDT=$83.19, 风险比例=1%, N=0.05, SUI=$1.16
   1单位 = $0.83 ÷ 0.05 ÷ $1.16 = 14.3 SUI
   当前A4买入12.6 SUI → 近似1单位

③ 加仓机制（可选开启）
   当SUI从建仓价上涨0.5N时触发第二层买入
   第2层 = 第1层的0.6倍 = 7.6 SUI
   全部4层满仓总敞口计算 → 是否超过总风险预算
```

**接入优先级：高**
- 不需要改架构，只在A3报告中新增N计算 + A4执行时读取N
- 立即收益：知道每笔交易的精确风险值，而不是"$15以上就能买"
- 长期收益：趋势行情时金字塔加仓放大利润
