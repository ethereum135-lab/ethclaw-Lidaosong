## 平台概述

Ave.ai 是一个**去中心化交易（DEX）数据分析平台**，集成了 **130+ 条区块链** 和 **300+ 个去中心化交易所（DEX）**，提供实时链上数据分析和交易执行功能。主要面向专业交易者和量化团队。

### 核心功能

- **代币分析与排名**：实时代币价格、交易量、流动性深度分析
- **链上数据监控**：Smart Money（聪明钱）追踪、KOL 持仓追踪
- **热门交易对**：按交易量、涨幅、热度排名的交易对列表
- **Pump 代币监控**：快速上涨代币的实时监控和狙击功能
- **Meme 代币追踪**：热门 Meme 币板块独立页面
- **复制交易（Copy Trading）**：跟随 Smart Money / KOL 自动交易
- **价格警报**：自定义价格提醒
- **K线图表**：专业级图表分析工具

### 平台模块

| 页面路径 | 功能说明 |
|----------|----------|
| `/rank` | 代币排行榜（按交易量、涨幅、热度等多维度排序） |

## 关键发现

### 1. 技术架构

- **前端**：Vue.js SPA 应用，服务器端渲染（SSR）
- **移动端**：独立移动站点 `m.ave.ai`
- **API**：提供规范的 REST API（文档在 docs.ave.ai）
- **安全**：使用阿里云验证码（Aliyun Captcha）防爬虫
- **部署**：托管于 Cloudflare，支持全球 CDN 加速

### 2. 数据维度

Ave.ai 支持的多维度数据分析：

- **链级别**：130+ 区块链网络数据（Ethereum、Solana、BSC、Polygon 等）
- **协议级别**：300+ DEX 协议数据（Uniswap、PancakeSwap、Raydium 等）
- **代币级别**：实时价格、交易量、流动性、持有者分布
- **地址级别**：Smart Money 地址追踪、大户持仓变动
- **交易级别**：新池子创建、大额交易、狙击交易

### 3. 特色数据服务

| 服务 | 说明 |
|------|------|
| **Smart Money** | 识别并追踪盈利地址的交易行为 |
| **KOL追踪** | 追踪知名交易者/影响者的链上操作 |
| **狙击机器人** | 新池子自动检测和快速买入 |
| **警报系统** | 多维度价格、交易量、链上事件警报 |

### 4. 平台限制

- 大部分功能需要登录/API Key 才能使用
- 实时数据通过 WebSocket 推送
- API 文档虽公开，但实际端点和速率限制需要 API Key

## 对量化团队的启示

1. **API集成价值**：Ave.ai 的 API 可获取 130+ 链的聚合链上数据，适合做跨链套利和链上信号分析

3. **新币捕获**：利用新池子监测功能，可开发打新/狙击策略
4. **链上数据丰富度**：远超传统 CEX 数据的维度，适合做链上数据分析模型
