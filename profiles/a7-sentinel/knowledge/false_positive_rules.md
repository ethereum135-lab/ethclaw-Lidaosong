# A7 舆情官 — 误报过滤规则
> 知识库文件 | 2026-05-11

## 一、硬过滤规则（绝对不告警）

### 1.1 日常闲聊模式
- "gm"、"gn"、"good morning"等日常问候
- 含"😂"、"🤣"、"💀"等纯表情推文
- 转发无评论或只有"👀"、"🔥"等单表情转发

### 1.2 广告/营销模式
- 含"my course"、"sign up"、"limited time"等营销关键词
- 含"presale"、"whitelist"、"mint now"等NFT/IDO推广
- 只有链接没有实质性评论的推文

### 1.3 重复/引用模式
- 引用其他人的推文但没有添加实质性评论
- 同一事件在30分钟内被多个KOL提及（只告警一次）

## 二、软过滤规则（需要LLM判断）

### 2.1 需要判断是否为"闲聊vs信号"
```
Elon: "Dogecoin is fun" → ❌ 闲聊，不告警
Elon: "Tesla will accept Dogecoin for merchandise" → ✅ 信号，告警
```

### 2.2 需要判断事件规模
```
一家不知名DeFi项目被黑，损失$500K → ❌ 局部事件，不告警
Curve被黑，损失$50M → ✅ 系统性风险，P0告警
```

### 2.3 需要判断是否为旧闻重复
```
"Bitcoin hit $100K"（如果BTC已经在$100K附近横盘一周）→ ❌ 旧闻
"Bitcoin breaks $100K for first time" → ✅ 突破性新闻
```

## 三、误报处理流程

1. 每次误报 → 记录到误报日志 → 更新过滤规则
2. 连续2次同一类型的误报 → 生成新的硬过滤规则
3. 同一KOL连续3次制造误报 → 该KOL降级为"观察"而非"监控"
