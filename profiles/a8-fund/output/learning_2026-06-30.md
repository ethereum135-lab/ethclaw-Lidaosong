### 机构资金如何在Hyperliquid留下痕迹（关键洞察）

机构在Hyperliquid上开仓的模式与散户不同：

| 特征 | 机构/大资金 | 散户 |
|:-----|:-----------|:-----|
| **开仓时机** | 流动性窗口期（亚洲/美国重叠） | 全天均匀分布 |
| **仓位变化** | 阶梯式（多层限价单），OI平滑上升 | 一次性市价单，OI锯齿 |
| **退场模式** | 分批止盈，OI缓降 | 止损/爆仓，OI骤降 |
| **多空关系** | BTC多头=看多，不对冲 | 可能双向开对冲 |

              ▼             ▼          ▼              ▼
   ┌─────────────────┐ ┌──────────┐ ┌────────────┐ ┌──────────┐

   │ Etherscan大额   │ │175个市场 │ │DexScreener │ │DeFiLlama │

### 与现有系统的集成方案（无需修改a8_data_fetch.py，只需更新A8产出JSON的格式）

当前 `a8_data_snapshot.json` 的 INFLOW 信号只有单源输出。可以改为**三源合并输出**：

```json
{
  "cross_signals": [
    {
      "coin": "BTC",
      "sources": {
        "cex_netflow": "in|$52M|USDT|Binance",
        "hl_oi": "up|+15.2%|4h_interval",
        "dex_volume": "up|$892M|24h"
      },
      "confidence": "HIGH",
      "verdict": "三源确认 — 机构资金入场",
      "a3_boost": "+20"
    }
  ]
}
```

**A3读取时**：直接读取 `cross_signals` 数组，按 `confidence` 和 `a3_boost` 字段加分，不再需要自己拼合多个信号。
