## 核心要点（3条）

### 🟢 要点一：False Discovery Rate (FDR) 控制 — 从单信号阈值到多信号错误率控制

**理论：** FDR（Benjamini & Hochberg 1995）定义了假阳性在总被发现信号中的比例 FDR = FP / (FP + TP)。与FWER（控制至少一次假阳性的概率）不同，FDR在多重比较场景下更具统计功效（power），因为它允许一定比例的假阳性——这正是A7的需求场景。

**应用到A7：** 当前A7的告警规则（权重×强度≥10）是单信号硬阈值决策。在多源信号场景下（同时监控多个KOL+多条新闻），需要做多重比较校正。具体方法：

1. **BH过程**：将所有候选告警按p值（或信号强度）排序，从最强开始依次判断，直到`p_i ≤ (i/m) × α`停止。这比固定阈值更精确地控制误报率。
2. **Bonferroni vs FDR选择**：当告警数量少（<5/轮）时用Bonferroni；当数量多（>5/轮，如同时监控数十个新闻源）时用FDR，FDR能避免过度严厉的惩罚漏掉真实信号。
3. **应用到A7**：将权重×强度映射为"告警可信度得分"，在每轮监控中收集所有候选信号，用FDR程序选择哪些真正值得写入alert.md。

**适配A7的简化实现：**
```python
# FDR控制伪代码用于A7告警判断
signals = [  # 所有候选告警，按可信度排序
    {"source": "Elon Musk", "score": 18, "content": "DOGE to the moon"},
    {"source": "Twitter user", "score": 6, "content": "BTC 100k next week"},
    {"source": "News site", "score": 4, "content": "ETH upgrade rumor"},
]
threshold = bh_procedure(alpha=0.10, m=len(signals))
alerts = [s for s in signals if s["score"] >= threshold]
# FDR 保证假阳性比例 ≤ 10%
```

### 🟢 要点二：Sequential Change-Point Detection — 市场状态转换自适应的动态阈值

**理论：** CUSUM（Page 1954）和贝叶斯变化点检测（BEAST: Zhao et al. 2019）用于在时序数据中检测分布变化。CUSUM累加Log-Likelihood Ratio，超过阈值时告警。BEAST将时序分解为趋势+季节+变化点，用贝叶斯Ensemble平均多个模型。

**应用到A7：** 当前F&G阈值是静态的（<20恐慌，>80贪婪），但在不同市场状态下（高波动vs低波动），同样的F&G值有不同的含义。

1. **CUSUM用于市场波动率变化检测**：追踪BTC的5分钟波动率序列，当波动率结构发生变化（如从日均1%跳到日均3%）时，自动调整A7的告警敏感度。
2. **BEAST用于F&G时间序列分析**：对F&G的7天序列做变化点检测，区分"正常波动"和"结构性变化"（如F&G从70骤降到30是在一天内完成的突变 vs 三天内完成的趋势）。
3. **动态阈值公式**：`告警阈值 = 基线阈值 × (当前波动率 / 历史平均波动率)`，高波动时提高阈值抑制误报，低波动时降低阈值不错过信号。

**与Cycle 2的ATR自适应阈值的区别：** Cycle 2的ATR自适应基于价格波动的简单缩放。Cycle 3的变化点检测能识别"结构变化"——ATR的长期均值如果也在漂移，变化点检测能提前预警"波动体制变了"，比ATR反应更快。

### 🟢 要点三：Multi-Armed Bandit for Online Threshold Optimization — 在不知标签的情况下自校准

**理论：** Multi-Armed Bandit（MAB）是探索-利用的经典框架。ε-greedy：以概率ε探索新阈值，以1-ε使用当前最优阈值。Thompson Sampling：用贝叶斯方法维护每个阈值的收益分布，从后验采样决定。

**应用到A7：** A7面临的核心问题是"没有标注数据"——我们不知道哪些告警是真阳性，哪些是假阳性。但有一件事是确定的：

**反馈信号：** ZH的响应。如果A7告警了ZH有反应（复盘时引用、导致策略调整）= 真正的阳性。如果A7告警了ZH没反应 = 误报。虽然反馈有延迟（ZH每天看一次），但足够作为MAB的reward信号。

**具体实现：**
```python
class AlertThresholdBandit:
    """用ε-greedy在线优化告警阈值"""
    def __init__(self, thresholds=[8, 10, 12, 14, 16]):
        self.thresholds = thresholds
        self.Q = {t: 0.0 for t in thresholds}  # 平均奖励
        self.N = {t: 0 for t in thresholds}    # 尝试次数
        self.epsilon = 0.15                     # 探索率
    
    def select_threshold(self):
        if random() < self.epsilon:
            return choice(self.thresholds)  # 探索
        return max(self.Q, key=self.Q.get)   # 利用
    
    def update(self, threshold, zh_reward):
        """zh_reward: ZH确认引用=1, 忽略=0"""
        self.N[threshold] += 1
        self.Q[threshold] += (zh_reward - self.Q[threshold]) / self.N[threshold]
```

**优势：**
1. 不需要标注数据——从ZH的自然行为中隐式学习
2. 能适应市场变化——如果行情变了导致误报增多，阈值会自动调高
3. 与FDR控制互补——FDR做单轮内的多重比较，MAB做轮次间优化
