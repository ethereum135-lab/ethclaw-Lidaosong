全局战略判断 — 纳瓦尔第一性原理

纳瓦尔的核心思维：不要用类比思考，要从第一性原理出发。 不要问"别人怎么做交易系统"，要问"这个系统的本质是什么"。

"财富需要杠杆。代码和资本是最高形式的杠杆 — 它们在你睡觉时为你工作。" — Naval Ravikant
第一性原理：交易系统的本质是什么？
交易系统的本质 = 概率游戏 + 风险管理 + 复利效应

每一笔交易不需要都赚钱，只需要：
① 胜率 > 50%（或盈亏比 > 1.5）
② 单笔亏损有上限（风控）
③ 正期望值 × 交易次数 = 复利增长

当前系统的问题：不是策略不好，是没有验证过正期望值。 RSI < 35 买入在理论上是对的，但从未用历史数据验证过胜率。
杠杆：我们拥有什么杠杆？
代码杠杆：mean_rev_bot.py 每5分钟自动扫描20个币，一个人永远做不到
资本杠杆：$280（币安$208 + 火币$71），小但可复利
时间杠杆：cron 24/7 运行，睡觉时也在交易
知识杠杆：每笔交易的数据都在积累，学会分析就能持续优化

关键洞察：代码+资本+时间 = 三重杠杆，但缺少"知识杠杆"的闭环 — 交易数据没有被用来反哺策略优化。
复利：什么在复利增长？
资金复利：每天0.2% → 年化730%（理论值，实际目标日0.1-0.3%）
知识复利：每天分析10笔交易 → 3个月理解900笔交易的模式
系统复利：每次优化参数 → 下次交易胜率更高 → 更多数据 → 更好的优化

当前断裂点：交易完成后没有复盘闭环。每笔交易的结果没有被分析、归因、反馈到下一笔。
特定知识：什么是最有价值的特定知识？
不是"会写Python"，不是"懂RSI"，而是：
"知道哪个RSI阈值在当前市场状态下买入，胜率最高"

这种知识无法从书本获得，只能从自己的交易数据中提炼。 这就是为什么复盘闭环是整个系统最关键的环节。

核心学习方法论 — 刻意练习 × 高效学习

1. 费曼技巧 — 用简单话解释
每学一个概念，用"教给完全不懂的人"的方式写一遍。 写不出来 = 没真懂。这是检验理解的唯一标准。
每天复盘日志里，用一句话解释当天最有价值的一笔交易"为什么赚/亏"
2. 主动回忆 — 不看资料默写
看完资料后关掉，凭记忆默写核心要点。大脑在"提取"时记忆最深， 在"重读"时记忆最浅。
学完RSI原理后，不看任何资料，手写RSI公式和3个应用场景
3. 交错练习 — 不要只练一种
不要一天只看RSI，要RSI + 量比 + 布林带 + 市场情绪混合学习。 大脑在"切换不同但相关主题"时，建立更深层的连接。
每天学习计划：20分钟RSI → 20分钟量价关系 → 20分钟风险管理 → 交错进行
4. 即时反馈 — 刻意练习的核心
刻意练习和普通练习的区别 = 有没有即时反馈。 每笔交易5分钟后就知道结果，这是天然的训练场。 但前提是：必须记录每笔交易的完整上下文（RSI值、量比、F&G、入场价、出场原因）。
给mean_rev_bot加交易日志：每笔交易记录入场的全部指标值，出场时记录结果和原因
5. 组块化 — 从小到大
不要一上来学"量化交易"，要拆成： RSI怎么算 → RSI什么时候准 → RSI+量比怎么组合 → RSI+量比+止损怎么配合 → 完整策略。 每个组块练到"不假思索"再进下一个。
本周只练一个组块：RSI < 35的买入信号在15m周期上，历史胜率到底是多少
6. 突破舒适区 — 练最弱的部分
人本能地重复练已经会的，回避不会的。 刻意练习 = 专门挑"做不好但能改进"的环节反复练。
当前最弱：止损设置。本周专攻"F&G联动止损在不同市场状态下被打掉的概率"

D4
第4天
学透布林带的第一性原理
手写布林带公式：SMA(20) ± 2×StdDev(20)
理解：布林带本质是"过去20根K线的价格分布范围"，±2σ覆盖95%的正常波动
问自己：为什么跌破下轨是买入信号？什么情况下跌破下轨后继续跌？如何区分？
关键洞察：布林带在低波动期收窄 → 突破后波动扩大 → 这是"布林带挤压"信号
能画出布林带收窄→扩张的示意图，并解释为什么收窄后更容易出现大波动
D5
第5天
理解量比和成交量的本质
量比 = 当前K线成交量 / 过去20根K线平均成交量
理解：量比>2 = 有人在大量买入/卖出 = 可能是趋势启动或FOMO
问自己：RSI超卖 + 量比>2，该买还是不该买？为什么策略里设置了量比>2拒绝入场？
用实际数据验证：找3个RSI<35且量比>2的案例，看后续走势是反弹还是继续跌
能用数据证明：量比>2时RSI超卖信号的胜率是否真的更低

第6天

理解为什么策略在极度恐惧时放宽止损（-9%）：因为正常波动大，-6%会被打掉

5条铁律 — 整个学习过程中不可违反

铁律一：先验证再相信
任何"策略有效"的说法，必须用数据证明。RSI<35买入"理论上"能赚钱？拿30天数据跑一下。没有数据支撑的信念 = 赌博。
铁律二：每天必须有输出
每天结束时手里必须有"产物"：一段代码、一个分析报告、一张资金曲线图。没有输出的一天 = 浪费的一天。输入不等于学习，输出才是。
铁律三：只改一个变量
每次只改一个参数，然后观察效果。同时改RSI阈值和止损和仓位 = 无法知道是哪个改动导致的盈亏变化。控制变量法是基础。
铁律四：用亏损当老师
每笔亏损比每笔盈利更有价值。亏损说明策略的盲区在哪。记录每笔亏损的完整上下文，30天后回头看，模式会浮现。
铁律五：不要中断
每天2小时，30天不间断。间断3天=前面的积累归零。大脑的遗忘曲线在24小时内最陡，每天接触是保持记忆的唯一方法。
