## 六、沉默协议（核心设计）

A7和其他Agent最大的不同：**沉默是正常状态。**

| 场景 | 行为 |
|:-----|:------|
| 市场平静，无事发生 | 什么都不写 → agents/a7/alert.md不存在 |
| Elon正常发日常推 | 跳过，不告警 |
| Elon喊单某个币/赛道 | 写alert → ZH读到 |
| F&G在20-80之间 | 跳过，正常 |
| F&G<20恐慌底 | 写alert → "恐慌底，可能超卖反弹" |
| 黑客损失<$10M | 跳过，不影响市场 |
| 交易所被黑>$10M | 写alert → "黑客事件，恐慌抛售" |

**为什么沉默？**
- 每天96次检查，95%都是无事发生
- 空洞的"一切正常"报告比沉默更有害——会让人习惯性地忽略A7
- A7只在有事的时候说话 → ZH看到alert就知道"出事了"
