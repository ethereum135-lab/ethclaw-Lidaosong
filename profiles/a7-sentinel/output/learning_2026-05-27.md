## 核心洞察一：多层置信评分机制

**理论**：当前A7使用固定 `weight × intensity ≥ 10` 的二值判定，容易误报。真实信号有多个"确认因子"，噪音缺乏这些因子。引入多维置信评分，将原始权重动态调整为信号强度。

**应用**：用 `confidence_score = weight × intensity × R × P × S × C ≥ threshold` 替代二值判定

| 因子 | 符号 | 说明 | 实现方式 |
|:-----|:----:|:------|:---------|
| **时效衰减** | R | 事件时间越久，置信越低。半衰期30分钟 | `e^{-λt}`，t=事件距今分钟数，λ=ln2/30 |
| **价格确认** | P | 事件后5分钟内价格是否异动且方向一致 | 查币安5min K线，变动<0.3%扣分 |
| **源历史可信度** | S | 该KOL近30天"命中率"（事件后价格变动>0.5%的比例） | 维护source_history表，新源默认0.5 |
| **语义强度矫正** | C | 而非硬编码1/2/3。区分"哈哈"(0.1)和"$DOGE TO MOON"(0.9) | NLP情感得分映射到0-1 |

**推荐阈值**：confidence_score ≥ 6时告警。亚洲盘可降到4以捕捉流动性不足时的早期信号。

## 核心洞察二：事件指纹去重 + 多源交叉验证

**理论**：同一重大事件（如"SEC起诉Binance"）被所有KOL和新闻源重复报道，造成重复告警。同时单来源的煽动性推文极大概率是谣言。

**应用**：
1. **事件指纹生成**：用NLP提取实体（BTC/ETH/DOGE/hack/pump等）+ 时间窗口 → sha256指纹
2. **去重窗口**：同一指纹30分钟内仅保留首个事件，后续仅更新交叉验证计数
3. **交叉验证得分**：

| 来源数 | 得分 |
|:------:|:----:|
| 1个来源 | 0.3 |
| 2个不同来源 | 0.8 |
| ≥3个来源 | 1.0 |

4. **特殊处理**：匿名账号(权重=1) + 靶向级强度(3x) → 交叉验证得分强制0.1，几乎不告警

**解决的具体问题**：
- ✅ 语义重复告警（多URL同一事件）
- ✅ 单源谣言误报（匿名账号喊单/唱空）
- ✅ shilling/pump group集体喊单

## 核心洞察三：反向因果关系检测（前置价格/成交量异常检查）

**理论**：A7最严重的误报来源——KOL发推时价格已提前异动。市场已PRICE IN，A7不该再为此告警。另外，FUD放荷/延迟新闻/跟风补推都属于反向因果关系。

**应用**：对每候选事件，先检查事件前1小时的行情：

```python
pre_change = (event_time_price - 1h_ago_price) / 1h_ago_price
volume_z = (event_volume - 24h_avg_volume) / 24h_std_volume

if abs(pre_change) > 2% and volume_z > 2:
    if 价格方向 == 事件情绪方向:
        置信 *= 0.1  # 随波逐流——价格已动，KOL跟风
    else:
        置信 *= 0.8  # 潜在反转信号
```

**三种常见误报的处理**：

| 误报类型 | 检测 | 惩罚 |
|:---------|:-----|:----:|
| 延迟新闻 | 新闻时间戳晚于价格首次跳变>10分钟 | 置信×0.5 |
| 跟风补推 | 价格已涨/跌2%+后KOL才发推 | 置信×0.1 |
| FUD噪音 | 负面关键词10分钟内暴涨>3σ但价格变动<0.5% | 置信归零 |

## 回答：怎么让A7的告警更准、误报更少？

### 优先级1（立即见效）：替换二值判定为置信评分
当前 `weight × intensity ≥ 10` 的问题：
- Elon说"哈哈" → 10×1=10 → 告警 ❌（误报）
- 行业KOL说"$DOGE to the moon" → 2×3=6<10 → 不告警 ❌（漏报）

换 `confidence_score = weight × intensity × R × P × S × C ≥ 6`：
- Elon说"哈哈" → 10×1×1.0×0.1×0.5×0.1 = 0.05 → 不告警 ✅
- 行业KOL说"$DOGE to the moon" + 价格确已涨1% + 非跟风 → 2×3×1.0×1.5×0.5×0.9 = 4.05 → 不告警（还需多源验证）✅
- Elon说"$DOGE to the moon" + 价格涨2% + 非跟风 → 10×3×1.0×1.5×1.0×0.9 = 40.5 → 立即告警 ✅

### 优先级2（中等工程量）：事件去重 + 交叉验证
在当前search循环中，对搜到的每条结果做：
1. 提取实体 → 生成指纹
2. 查30分钟窗口内是否已有相同指纹
3. 有则跳过（不重复告警）
4. 跨来源计数 → 调整置信

### 优先级3（最复杂但消除最大误报源）：反向因果检测
需要在告警前调币安API查前1小时价格/成交量。这步接入后能消除：
- 跟风补推误报（~40%的误报来源）
- 延迟新闻误报（~25%）
- FUD放大噪音（~20%）

### 总结影响

| 改进项 | 预期减少误报 | 工程复杂度 |
|:-------|:-----------:|:----------:|
| 置信评分（替代二值判定） | 50%+ | 低（改公式即可） |
| 事件去重+交叉验证 | 30% | 中（需存储指纹） |
| 反向因果检测 | 30% | 高（需调币安历史K线） |
