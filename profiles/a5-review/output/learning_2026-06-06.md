## 第③步：用综合视角检视本周交易

### 1. 用规则1看本周的HEI +6.73%硬止损（周五）

**数据：** HEI买入后触硬止损-6.73%，退出原因"HEI-6.54%低于止损0.0929"

**按规则1三问：**

- ② HEI有链上/生态故事吗？ → Helium是去中心化物联网网络，真实用例 → **是**
- ③ 趋势初期/末期？ → HEI 24h+下跌，但物联网赛道刚起步 → **初期**

**结论：** 三问全"是" → 不应退出。硬止损-5%对HEI这种高波动币过紧。应使用动态止损（ATR-based）而非固定-5%。

### 2. 用规则1看POND 6月5-6日双杀（周五→周六）

**数据：** POND +11.35%减半仓(BTC crash触发) → 次日POND剩余清仓 -1.4%

**分析：** POND在BTC崩盘中曾涨+11.35%——说明它有独立于BTC的驱动力。但次日A4用SELL_NOW conf=8清仓了剩余仓位。从POND的走势看，它在BTC反弹后仍有波动空间，但A4的15m↓短周期转跌信号把它洗出去了。

**教训：** 一个BTC崩盘时上涨+11%的币，说明有独立驱动力。次日的15m↓回调可能是短暂跟随，不应作为清仓信号。

### 3. 用规则2看周五（06-05）的29笔卖出大清洗

**数据：** 06-05总P&L -267.1%（含-100% DQW污染），仅1笔correct +11.35%，15笔wrong，13笔neutral

**根因（四层归因）：**
- L1(选币)：不是选币问题——ZBT(-12.2%)/AT(-4.5%)/JST(-7.5%)这些是A4的轮换清理行动
- L2(执行)：不是执行问题——硬止损和轮换都正确执行了
- L3(策略)：**核心问题**——A4在06-05间进行了一次全仓轮换清理，但轮换触发条件(最弱仓WATCH conf=4)在弱市中产生大量亏损退出。因为所有仓位在弱市中都表现弱，轮换变成了"割肉换仓→割肉换仓"的死亡螺旋
- L4(环境)：**环境问题**——BTC从$63K跌至$59K，SSH断连，市场恐慌情绪蔓延

**关键发现：** 在系统性弱市中（BTC日跌>3%），"轮换最弱仓"策略应自动暂停。弱市时所有仓都弱，轮换等于在底部换仓——换入的TUT/STG/HEI等新仓也被迫硬止损出局。

```json
{
  "symbol": "TUT",
  "reason": "刚启动+8.39%·vol$3.63M·TRADING",
  "weak_market_tolerance": {
    "enabled": true,
    "max_drawdown": -8,
    "hold_window_hours": 8,

```
