## 第②步：提炼2条CZ判断规则

### 🏆 规则1：量价匹配法则 — "量不骗人，价可以骗人"

**CZ的视角：** 一个币涨20%但量只有$100K，跟一个币涨5%但量$1B，CZ会选择后者。因为后者是真实资金在推。

**A5的运用规则：**

```python
def cz_volume_check(volume_24h, price_change, baseline_volume):
    """CZ式交易判断：量价匹配检查"""
    volume_ratio = volume_24h / baseline_volume if baseline_volume > 0 else 0
    
    # 条件1：绝对值门槛（避免$100K量伪信号）
    if volume_24h < 1_000_000:
        return "🔴 拒绝 — 绝对量<$1M，流动性险"
    
    # 条件2：量比≥1.5x才认可
    if volume_ratio < 1.5:
        return "🟡 观察 — 量未放，可能是假突破"
    
    # 条件3：量比和涨幅的关系（放量不涨=吸筹，放量大涨=真突破）
    if volume_ratio >= 3 and price_change > 5:
        return "🟢 真突破 — 量价齐升，资金真实涌入"
    elif volume_ratio >= 2 and price_change < 2:
        return "🟡 吸筹 — 资金在进但价格不动，跟踪突破"
    
    return "🟡 正常 — 需要持续观察"
```

**CZ会说：** "CREAM 82.6%涨幅但仅$130K量？这是陷阱。真正的好交易，量比价先走。"

### 🏆 规则2：反事实检查 — "如果今天没持有，我会买吗？"

**CZ的视角：** 一个仓位亏了不代表"它会回来"。最贵的四个字是"总会回来的"。决定是否持有，要看"如果我现在是空仓，我会买入这个币吗？"

**A5的运用规则：**

```python
def cz_counterfactual_check(position, candidate_pool):
    """CZ式反事实持仓检查"""
    # 反事实问题：如果我现在有$X现金，我会买这个币吗？
    would_buy_today = position['score'] >= 80 and position['volume'] >= 1_000_000
    
    if not would_buy_today and position['pnl_pct'] < -3:
        return "🔴 建议清仓 — 反事实说NO + 已亏损>3%"
    elif not would_buy_today:
        return "🟡 观察持有 — 反事实说NO但亏损不大，给观察期"
    else:
        return "🟢 继续持有 — 反事实说YES"
```

**CZ会说：** "PARTI亏了-4.74%还在说'有亏损仓位不轮换'？你问问自己：如果今天你手上是现金$34.62，你会买PARTI吗？如果答案是NO，立即清仓，拿回现金去换ZEC。"
