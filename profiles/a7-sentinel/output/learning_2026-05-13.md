## 核心要点

### 要点一：社交媒体情绪分析的三层过滤模型

**理论：** 纯量的情绪分析（正面/负面词计数）噪声比信号高10:1。有效的监控需要三层递进过滤：

| 层级 | 方法 | 作用 | 误报率 |
|:----:|:-----|:----|:------:|
| L1 | 关键词+量级检测 | 快速扫描原始信号 | ~70% |
| L2 | 来源可信度加权 | 按KOL历史影响力加权 | ~40% |
| L3 | 市场验证+交叉引用 | 看价格是否有初始反应 | ~15% |

**应用到A7：**
- 当前A7只有L1（web_search关键词匹配）。需要在alert中加入L2权重（Elon推 vs 山寨KOL推，权重差应>10x）
- 加入L3：检测到事件后，先看BTC/相关币种是否有>1%的初始价格波动，再决定是否告警
- 三层的核心原则：**L1放水（不漏），L2过滤（去噪），L3确认（防误报）**

### 要点二：事件驱动交易的"事件-时间-幅度"三维评估

**理论：** 不是所有事件都值得告警。评估一个事件是否重要的三个维度：

1. **事件性质（0-10分）**：
   - 10分：黑客攻击（>`$100M`）、监管禁令、主网上线
   - 8分：Elon喊单、CZ公告、重大合作伙伴
   - 4分：KOL一般性评论、技术升级预告
   - 1分：日常讨论、FUD/FOMO情绪波动
   
2. **时间窗口（分钟）**：
   - 0-15分钟：最佳入场/反应窗口
   - 15-60分钟：次优窗口，多数机构已经反应
   - 60分钟+：情绪已经消化，不要追涨杀跌
   
3. **幅度预期（%）**：
   - 大事件（>15%波动）：黑客/监管/Elon喊单
   - 中事件（5-15%）：CZ公告/Saylor持仓
   - 小事件（<5%）：一般新闻/情绪波动

**应用到A7：**
- 当前A7所有告警一视同仁。需要加入"事件评分"机制——A7告警的同时给出影响评分
- 例如："Elon推DOGE → 影响分8/10, 预期波动5-15%"
- 但评分必须控制在一行内（alert≤10行的铁律）

### 要点三：误报过滤的"静默期/确认机制"

**理论：** 社交媒体最大的陷阱是"假突破"型舆情——同一消息被反复报道，每次看起来都像新的。

**三个反误报机制：**

1. **去重机制（Dedup）**
   - 同一事件60分钟内不重复告警（当前config.yaml已配置dedup_window: 60）
   - 但需要语义去重，不仅仅是URL去重。例如3家媒体报道同一黑客攻击，URL不同但事件相同
   - 方法：对告警内容做摘要Hash，摘要相似度>70%视为重复
   
2. **确认机制（Confirmation）**
   - 单来源不告警，至少2个独立来源确认才告警
   - 例外：Elon/CZ的原创推特是单来源例外（因为他们本身就是事件源头）
   - 这条规则可以降低约50%的误报
   
3. **历史基线（Baseline）**
   - 记录过去7天同时间段的关键词出现频率
   - 当前频次超过基线3σ（标准差）才视为异常
   - 例如：平时每小时提到"Bitcoin"是100次，突然跳升到300次+ → 有事发生
   - 对A7来说：不需要实时词频统计，但可以用时间维度判断——"这条新闻刚出来1小时内"vs"已经发酵几天的旧闻"

## 应用到A7的改进方案

### 当前A7的问题诊断

| 问题 | 严重程度 | 表现 |
|:----|:--------:|:-----|
| 只有L1关键词匹配 | 🔴 高 | 任何Elon相关推文都触发，无法区分"哈哈"和"DOGE TO THE MOON" |
| 无事件评分 | 🟡 中 | 10分事件和1分事件一样通告，ZH无法快速判断优先级 |
| 无确认机制 | 🟡 中 | 同一事件通过不同渠道重复告警 |
| 无L3验证 | 🟡 中 | 市场已经消化的旧闻继续触达 |

### 优先级改进清单

```
P0 [本周] 加入事件评分字段（每个alert附带影响评分1-10行内）
P1 [本周] 实现语义去重（不是URL去重，是内容摘要去重）
P2 [双周] 加入L2来源可信度权重（Elon=10x, CZ=8x, Saylor=5x, 其他=1x）
P3 [月度] 加入L3价格验证（检测到事件后查当前价格波动）
```

### 具体实现思路

1. **事件评分加入alert格式**：
   ```
   ## 影响评分：[8/10]
   ## 事件：[Elon Musk推文提及DOGE]
   ## 来源：[twitter.com/elonmusk]
   ## 预期波动：5-15%
   ## 建议：[关注DOGE开盘后走势]
   ```

2. **语义去重**：
   - 每个alert生成一个SHA256(content_hash)
   - content_hash = sha256(event_type + event_summary)
   - 60分钟内相同hash不重复告警
   - 告警前先查历史hash表

3. **来源可信度表**：
   ```
   Elon Musk → 权重10x（直接告警）
   CZ → 权重8x（直接告警）
   Michael Saylor → 权重5x（直接告警）
   Arthur Hayes → 权重3x（需要L3确认）
   Ansem/Bankless → 权重2x（需要L2+L3确认）
   匿名推特 → 权重1x（需要多来源确认）
   ```

## 本周学习总结

**最大收获：** A7目前仅处于L1（关键词匹配）阶段，离真正的舆情哨兵还有L2（可信度加权）和L3（市场验证）的差距。

**核心改进方向：** 
1. 区分"噪音"和"信号"的关键不是关键词匹配，而是**来源可信度 + 事件评分 + 市场验证**三层过滤
2. A7的铁则"宁可漏报不可误报"是对的，但漏报分两种：真漏报（Elon喊了没看到）和有意漏报（不重要的推文不报）。后者是能力，前者是事故
3. 加入事件评分后alert会增加字段，但必须控制在13行以内（比10行预留3行给评分）
