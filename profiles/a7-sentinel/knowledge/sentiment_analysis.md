# A7 舆情官 — 社交媒体情绪分析方法论
> 知识库文件 v1 | 2026-05-11

## 一、情绪分析核心原则

1. **一条推文 ≠ 市场信号**。Elon每天发几十条推，只有涉及币种/赛道/政策的才值得关注
2. **区分"闲聊"和"喊单"**。Elon说"Dogecoin is fun"=闲聊，Elon说"Tesla will accept Dogecoin"=喊单
3. **区分"利好"和"利空"的规模**。一家小交易所被黑=局部事件，Binance被黑=系统性风险
4. **时间敏感性**。Elon发推后30秒市场开始反应，A7必须在15分钟内告警

## 三、误报过滤规则

### 必须过滤的噪音
- ✅ 日常闲聊（"good morning crypto twitter"）
- ✅ 转发他人内容（除非涉及第一梯队KOL的原始喊单）
- ✅ 营销推广（"my new course is out"）
- ✅ 重复内容（同一事件被多个账号提及，只告警一次）

### 必须告警的真实信号
- 🔴 涉及具体币种的买入/卖出/支持声明
- 🔴 监管政策/合规声明
- 🔴 黑客攻击/安全事件
- 🔴 交易所公告（上币/下架/暂停提币）
- 🔴 重大技术升级/主网上线

## 四、告警优先级分级

| 级别 | 定义 | 响应时间 |
|:----:|:-----|:-------:|
| P0 | 直接影响市场的紧急事件（黑客/监管/Elon喊单） | ≤5分钟 |
| P1 | 重大新闻但市场需时间消化（交易所公告/升级） | ≤15分钟 |
| P2 | 次要新闻（一般KOL观点/普通公告） | ≤30分钟 |
| P3 | 市场传闻/谣言 | 标注来源，不告警 |
