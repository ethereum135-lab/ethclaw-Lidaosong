# 📚 A5 每日学习 — 2026-05-18（周一）

## 主题：赵长鹏（CZ）— 用「资本配置思维」而非「信号扫描思维」看交易

### 第①步：CZ核心理念提炼

#### 理念1：「全仓押注的信念 > 分散到100次彩票」
CZ最著名的操作：2013年听了Bobby Lee建议把10%资产投BTC，他卖掉上海的公寓全部买BTC。不是10%，是100%。他的逻辑是：**如果这个交易不值得你押上全部，那它根本不值得做。**

这与系统当前的模式形成鲜明对比——600笔交易，平均每笔P&L约$0.50，最大盈利$2.27(CHZ止盈)，最大亏损-$1.53(CRV止损)。CZ会说：600次都在玩$1的小游戏，没有一次是真正意义上的「好交易」。

#### 理念2：「速度是武器，但方向比速度重要」
Binance从2017年7月ICO到2018年4月成为全球最大交易所——仅用8个月。但CZ的核心不是「跑得快」，是**方向选对了**：坚持做现货交易平台（当时大家都在搞ICO），坚持用户优先（低费率+好体验）。

快+方向对 = 极快成功。快+方向错 = 极快破产。
系统当前的现状是：**方向不确定（信号正确率2-4%），速度很高（600笔/25天=24笔/天），结果=每天亏~$5。**

#### 理念3：「市场会自我修正，不要跟趋势对着干」
CZ在采访中说"市场总会自我修正"。意思是：价格涨得太多了会跌，跌得太多了会涨。**需要的是持仓等待，不是每天24次交易。**

### 第②步：提炼2条CZ判断规则

**规则1：好交易 = 你敢在这个价位重仓、持有3天不心慌**
用这条判断一笔交易是否值得做：
- 如果只敢买$20（一个三明治的钱）→ 这不是好交易，是噪音
- 真正的好交易：CHZ持有2天赚+$4.36——但仓位只有$21。如果系统敢买$200 CHZ → P&L = +$43.6
- CZ视角：仓位规模 = 信念的量化

**规则2：「方向错了，速度越快死得越快」**
- 如果一个人连续走反方向，他跑得越快只会越远
- 系统600笔交易中，E3/E4/E2三个主信号的正确率都<4%，意味着91-96%的时间方向是错的
- CZ会说：先停下来搞清楚方向，不要用20x速度跑错路

### 第④步：写入反馈（发现的新角度）

**致命发现：系统的本质不是「交易系统」而是「彩票系统」**

用CZ的眼睛看：
- **600笔交易** = 600张彩票
- **平均仓位$25-40** = 每张彩票0.5注
- **信号正确率2-4%** = 彩票中奖率3%
- **每天-5%累计亏损** = 买彩票的期望值

CZ的规则1（好交易=敢重仓）→ 系统没有一笔交易符合。
CZ的规则2（方向比速度重要）→ 系统用最高速度跑最不确定的方向。

**A3的改进方向（从CZ视角）：**
A3现在的问题是「选了很多个可能涨的币」但每个只推一个小仓位。CZ的哲学是：**如果你推了10个币，说明你其实一个都不确定。** 应该从候选池里选出最确定的那1个，然后重仓推它。

**A4的改进方向（从CZ视角）：**
CZ从开发期货交易软件起步（Bloomberg Tradebook），他最懂两件事：
1. **大钱不是从止盈来的，是从持仓来的**（CHZ持仓2天=好，大部分30分=差）
2. **频繁交易 ≠ 创造价值**（平台鼓励交易是因为平台赚手续费，交易者自己不应该给自己刷手续费）
