## 第二部分：真实经历库

### 经历1：BCH波段 — 正确的"吸筹→启动→止盈"全流程

```
日期: 2026-05-05
币种: BCH
买入: $398.25（吸筹区）
卖出: $411.35
持仓时间: 475分钟
盈利: +$14.60 (+3.29%)
核心经验:
  - 正确流程: 吸筹埋伏→放量启动→方向转弱止盈
  - A3四维分析本质上是重建了这个流程
  - 验证了"短线波段(数小时)适合小资金"的正确性
核心教训:
  - "系统为了完成任务不是盈利"——BCH赚了但系统没有学到为什么赚
  - 赚钱的交易没有产出经验值，亏钱的交易也没有
  - 每笔交易必须有经验值产出
```

### 经历2：NOT案例 — 放量启动被吸筹评分误杀

```
日期: 2026-05-08
币种: NOT
进场: +87%涨幅后进场
亏损: 约14U
核心经验:
  - 吸筹评分奖励"不动"、错杀"启动"
  - 第一根放量阳线(+5.38%, 量跳3x)被扣分——这个设计完全错了
  - 修复方案: NBZ专职化——早期信号独立Agent
核心教训:
  - 均值回归思维（价格越低越好）和趋势思维（越涨越要追）要分开
  - 不能用一个策略框架覆盖所有市场阶段
  - 老李说"短线策略核心是'价格要涨'"——不是价格便宜
```

### 经历3：E3亏损 — 出场趋势跟踪的失败

```
日期: 2026-05-05
亏损: -$64
核心诊断:
  - 入场: 均值回归（价格低位+吸筹）→ 正确
  - 出场: 趋势跟踪（等继续涨）→ 在小波动市场永远没机会出场
  - 根因: 两种策略在同一个交易框架里打架
核心教训:
  - 均值回归入场 = 必须均值回归出场（涨了就跑）
  - 趋势入场 = 必须趋势跟踪出场（设止损让利润跑）
  - 不能混合使用——这是系统核心矛盾
```
