#### J：归因层次分析法

**学什么：**
四层归因，每深入一层才是根因：
- L1 选了什么币（选币问题）
- L2 怎么执行的（执行问题） 
- L3 为什么这样决策（策略问题）
- L4 市场环境变了（环境问题）

大多数复盘停在L1或L2，真正的根因在L3、L4。

**具体操作：**
```bash
# 1. 学习归因分析
web_search "root cause analysis 5 whys trading strategy"
web_search "attribution analysis trading performance layers"

# 2. 从系统拉亏损最大的一笔交易
cd ~/zq_web4_trading_system
python3 -c "
import os, json
trades_dir = 'data/experience/trades'
trades = []
for f in os.listdir(trades_dir):
    if not f.endswith('.json'): continue
    with open(os.path.join(trades_dir, f)) as fh:
        d = json.load(fh)
    a = d.get('analysis', {})
    pnl = float(a.get('pnl_pct', 0))
    trades.append((pnl, a.get('symbol','?'), a.get('exit_reason','')[:60], a.get('lesson','')[:60]))
trades.sort()
pnl, sym, reason, lesson = trades[0]
print(f'亏损最大: {sym} {pnl:.1f}%')
print(f'退出原因: {reason}')
print(f'经验教训: {lesson}')
print()
print('L1 选币: 为什么选这个币?')
print('L2 执行: 入场/出场合理吗?')
print('L3 决策: 选币逻辑成立吗?')
print('L4 环境: 市场环境变了吗?')
"
```

#### K：信号衰减检测

**学什么：**
- 所有策略/工具都有生命周期
- 检测方法：将数据分为前中后三段对比
- 信号衰减的三个阶段：新鲜期→稳定期→退化期
- 系统当前598笔交易的信号是否衰减？

**具体操作：**
```bash
# 1. 学习信号衰减
web_search "signal decay trading strategy performance over time"
web_search "strategy degradation detection quantitative finance"

# 2. 检查系统信号衰减
cd ~/zq_web4_trading_system
python3 -c "
import json, os
trades_dir = 'data/experience/trades'
trades = []
for f in sorted(os.listdir(trades_dir)):
    if not f.endswith('.json'): continue
    with open(os.path.join(trades_dir, f)) as fh:
        d = json.load(fh)
    a = d.get('analysis', {})
    ts = f[:16]  # YYYY-MM-DD_HH-MM
    pnl = float(a.get('pnl_pct', 0))
    q = a.get('exit_quality','')
    trades.append((ts, pnl, q))

n = len(trades)
if n > 30:
    third = n // 3
    for label, seg in [('前1/3', trades[:third]), ('中1/3', trades[third:2*third]), ('后1/3', trades[2*third:])]:
        wins = sum(1 for _, p, _ in seg if p > 0)
        total = len(seg)
        avg = sum(p for _, p, _ in seg) / total if total else 0
        print(f'{label}: {total}笔, 胜率{wins/total*100:.0f}%, 平均P&L{avg:+.2f}%')
"
```

cd ~/zq_web4_trading_system
python3 -c "
import json
with open('data/experience/MASTER_EXPERIENCE.json') as f:
    m = json.load(f)
for sig, p in m.get('exit_signal_performance', {}).items():
    t = p.get('total', 0)
    c = p.get('correct', 0)
    if t >= 100:
        print(f'{sig}: {t}次 → ✅ 充足，正确率{c/t*100:.1f}%')
    elif t >= 30:
        print(f'{sig}: {t}次 → 👀 观察，正确率{c/t*100:.1f}%')
    else:
        print(f'{sig}: {t}次 → ❌ 不足，不下结论')
