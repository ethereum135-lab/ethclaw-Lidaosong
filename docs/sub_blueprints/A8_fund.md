## 3. 监控指标

| 指标 | 来源 | 用途 |
|------|------|------|
| 大额转账 | Etherscan | 鲸鱼动向 |
| 交易所流入/流出 | 链上数据 | 牛熊信号 |

| ETF流入/流出 | 公开数据 | 机构情绪 |

## 4. 数据流

```
Etherscan API + 链上数据
    ↓ A8监控
etherscan_watcher.py
    ↓ 写入
data/node_history.jsonl (节点历史)
    ↓ 被读取
A3牛币官 (资金面分析)
A4执行 (大额信号参考)
```
