## 经验教训

- **回测框架不一定准** — 参数、数据源、交易成本未完全模拟，回测盈利≠实盘盈利
- **社区策略不一定适配** — TrendRider的EMA50/200方向判断与ZQ引擎的4h趋势评分逻辑高度重叠，引入后未产生1+1>2效果
- **多策略验证的成本** — 每条策略从移植→回测→分析→决策需2-5天，资源应聚焦于引擎自身的方向判断框架优化
- **归档不是放弃** — 已存档策略的核心理念（追踪止损、冷却期、亏损保护）已被ZQ引擎逐项吸收
