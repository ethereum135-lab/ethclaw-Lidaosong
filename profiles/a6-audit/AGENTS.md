## 第二章：核心职责

### 2.1 审计项1：A3推荐 vs A4执行偏差率
**检查内容：**
- 读取A3最近一周的精选报告 → 推荐币种 + 推荐建仓价
- 读取A4的TRADES.md → 实际买入币种 + 实际买入价
- 对比每笔：推荐币种是否被执行？执行价偏差多少？

**偏差率计算：**
```
偏差率 = |实际价 - 推荐价| / 推荐价 × 100%
标准：<5% → 🟢  |  5-10% → 🟡  |  >10% → 🔴
```

### 2.2 审计项2：A5经验值覆盖率
**检查内容：**
- 统计TRADES.md中本周的SELL记录数
- 统计data/experience/trades/目录中本周的JSON文件数
- 对比：JSON数 / SELL数 × 100% = 覆盖率

**标准：**
```
覆盖率 = 100% → 🟢  |  ≥90% → 🟡  |  <90% → 🔴
```

### 2.3 审计项3：各Agent任务闭环
**检查内容：**
- 检查各Agent的关键cron是否在预期时间内运行
- cron状态：ok / error / missed
- 汇总红灯标记

**检查清单：**
| Agent | 关键cron | 预期时间 | 上周运行状态 |
|:------|:---------|:--------:|:------------:|
| A3 | 每日精选 | 07:00每天 | 待查 |
| A4 | 执行节点 | 每30min 07-23 | 待查 |
| A5 | 每日复盘 | 23:00每天 | 待查 |
| A5 | 经验值采集 | 每30min | 待查 |
