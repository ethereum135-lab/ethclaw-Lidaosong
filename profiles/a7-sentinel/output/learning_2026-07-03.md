## 3条核心要点

### 🟢 要点一：实时反馈学习（Active Learning with ZH）— 把人的判断变成训练信号

**理论背景：**
主动学习（Active Learning, Settles 2009）的核心思想是：模型主动选择最有价值的未标注样本请求人工标注，用最少的人工标注量达到最高的模型精度。三种经典采样策略：

1. **不确定性采样（Uncertainty Sampling）**：选择模型预测最不确定的样本（熵最高、预测概率最接近0.5）。对于A7，即选择权重×强度得分最接近阈值边界的候选告警，让ZH帮系统校准决策边界。
2. **委员会查询（Query-by-Committee, QBC）**：训练多个模型组成委员会，选择委员会分歧最大的样本（投票熵最高）。对于A7，即让多个判断维度（时序异常检测+关键词匹配+市场情绪）独立打分，当各维度意见不一致时请求ZH仲裁。
3. **期望模型变化（Expected Model Change）**：选择能使模型权重变化最大的样本。对于A7，即选择能最大程度改变阈值边界的告警事件。

**应用到A7的关键创新 — 隐式反馈提取：**
A7面临的核心问题是"没有显式标注数据"——ZH不会每天说"这条告警对了，那条错了"。但可以从ZH的行为中提取隐式反馈：

```python
# 隐式反馈提取机制
def extract_implicit_feedback(alert, zh_actions):
    """从ZH行为推断告警的真假阳性"""
    score = 0
    # 正面信号（真阳性可能性↑）
    if zh_actions.get('复盘中引用', False):      score += 1.0  # ZH在每日复盘中引用了→真阳性
    if zh_actions.get('通知A3/A4', False):       score += 0.8  # ZH转发给交易Agent→真阳性
    if zh_actions.get('更新NAVIGATION', False):   score += 0.6  # 导致策略更新→真阳性
    # 负面信号（假阳性可能性↑）
    if zh_actions.get('过去7天无任何后续', True):  score -= 0.5  # 告警后ZH毫无反应→可能是误报
    if zh_actions.get('后续市场未验证', False):    score -= 0.3  # 告警方向与市场实际走势相反
    return 'positive' if score > 0.3 else 'negative' if score < -0.2 else 'uncertain'
```

**对A7的具体价值：**
- ZH的"引用"或"忽略"行为本身就是训练信号——不需要ZH额外做任何操作
- 不确定性采样确保ZH看到的每个告警都"最能帮助系统学习"——ZH花时间看告警的双重收益
- 随着标注积累（约50条隐式反馈后），阈值决策边界会快速收敛到最优

**Bayesian隐式阈值更新：**

```python
import numpy as np
from scipy.stats import beta

class ActiveThresholdLearner:
    """基于ZH隐式反馈的Bayesian阈值更新"""
    
    def __init__(self, base_threshold=10.0, alpha_prior=2, beta_prior=10):
        # 先验：大多数告警应该是假阳性（减少误报的偏好）
        self.alpha = alpha_prior   # 正面反馈计数器+
        self.beta = beta_prior     # 负面反馈计数器+
        self.threshold = base_threshold
    
    def select_alerts_for_zh(self, candidates, k=2):
        """
        从候选池中选择最值得ZH看的k条告警
        策略：选择得分最接近当前阈值的（模型最不确定的边界样本）
        """
        scores = [c['score'] for c in candidates]
        # 找到最靠近阈值的k个
        distances = [abs(s - self.threshold) for s in scores]
        top_k_indices = np.argsort(distances)[:k]
        return [candidates[i] for i in top_k_indices]
    
    def update_from_feedback(self, zh_referenced, alert_score):
        """
        ZH引用该告警 → positive update (alpha+1)
        ZH忽略该告警 → negative update (beta+1)
        
        阈值向beta分布的后验均值移动
        """
        if zh_referenced:
            self.alpha += 1
        else:
            self.beta += 1
        
        # 后验均值 = alpha / (alpha + beta)
        posterior_false_positive_rate = self.beta / (self.alpha + self.beta)
        
        # 新阈值 = 基础阈值 × (1 + posterior_false_positive_rate)
        # 如果某条告警被ZH忽略（假阳性），提高阈值减少类似告警
        self.threshold *= (1 + 0.1 * posterior_false_positive_rate)
        
        return self.threshold
```

**核心优势与不同：**
| 维度 | C3 MAB方法 | C4 Active Learning |
|:----|:----------|:-----------------|
| 反馈类型 | 纯隐式（是否被引用） | 隐式+不确定性采样（有选择地学习） |
| 学习速度 | 慢（等ZH自然引用） | 快（主动告知ZH哪些告警最有信息量） |
| 抗噪声 | 弱（单条误报影响大） | 强（Bayesian先验平滑） |
| 数据效率 | 每100条告警收敛 | 每50条不确定性样本收敛 |

### 🟢 要点二：AnomalyTransformer — 用关联差异发现市场异常模式

**理论背景：**
AnomalyTransformer（Xu et al. 2022, ICLR）是时序异常检测的前沿工作，核心创新在于**最小极大熵关联差异（Minimax Association Discrepancy）**。

传统时序异常检测方法（如VAE、Isolation Forest）对**点异常**（单时间点的离群值）敏感，但对**模式异常**（多个时间点上的联合偏离）不敏感。AnomalyTransformer从Transformer的自注意力机制出发，检测**时序关联模式的异常**——一段序列内部的"关联结构"是否和正常分布不同。

**核心公式与原理：**

1. **先验关联（Prior Association）**：用可学习的高斯核`G`计算相邻时间步的关联性，对局部上下文敏感
   ```
   P(i, j) = softmax( (G(Q_i, K_j) / τ) )
   其中G是高斯核：G(a, b) = ||a - b||² / (2σ²)
   ```

2. **序列关联（Series Association）**：用标准Transformer自注意力计算远距离关联
   ```
   S(i, j) = softmax( (Q_i · K_jᵀ) / √d )
   ```

3. **关联差异（Association Discrepancy）**：
   ```
   AD(P, S) = KL(P || S) + KL(S || P)
   ```
   正常时序中，局部关联和全局关联应该一致（P ≈ S）。
   异常发生时，局部和全局的关联结构会分裂（P ≠ S）。

4. **最小极大熵训练**：
   - 极小化阶段：最小化AD，使P和S一致（正常数据上一致）
   - 极大化阶段：最大化AD，迫使模型区分正常/异常模式
   - 训练完成后，异常时间点的AD会显著高于正常时间点

**应用到A7的具体方案：**

**为什么AnomalyTransformer比VAE更适合A7？**
| 维度 | VAE（C4黑天鹅） | AnomalyTransformer |
|:----|:-------------|:-----------------|
| 检测类型 | 点异常/分布外 | 模式异常/时序关联断裂 |
| 敏感目标 | 极端数值 | 反常的价量关系模式 |
| 对A7场景 | 检测F&G暴跌等极值 | 检测"看起来正常但关联结构异常"的模式 |
| 计算量 | 轻量（CPU可跑） | 中等（需Transformer） |
| 误报率 | 高（极端行情=高误报） | 低（区分市场状态vs真正异常） |

**A7简化版AnomalyDetector（不依赖PyTorch的近似实现）：**

```python
import numpy as np
from sklearn.gaussian_process import GaussianProcessRegressor

class LightweightAnomalyTransformer:
    """
    轻量AnomalyTransformer——用KDE近似先验关联 + 
    余弦相似度近似序列关联
    适合A7的CPU环境，无PyTorch依赖
    """
    
    def __init__(self, window_size=24, embedding_dim=16):
        self.window = window_size  # 24个时间步（2小时@5分钟）
        self.emb_dim = embedding_dim
        
        # 正常数据的关联结构缓存
        self.prior_cache = []   # 局部关联矩阵（滑动窗口）
        self.series_cache = []  # 全局关联矩阵
    
    def compute_association_discrepancy(self, sequence):
        """
        sequence: (window, features) — 当前2小时的市场特征序列
        返回每个时间步的异常分数
        """
        # ① 先验关联（局部高斯核）
        prior = self._gaussian_prior(sequence)  # (window, window)
        
        # ② 序列关联（全局自注意力近似）
        series = self._cosine_series_attention(sequence)  # (window, window)
        
        # ③ 关联差异
        kl_div = self._kl_divergence(prior, series)
        
        return kl_div  # (window,) — 每个时间步的异常分数
    
    def _gaussian_prior(self, seq):
        """用时间距离的指数衰减近似高斯核先验"""
        n = len(seq)
        prior = np.zeros((n, n))
        for i in range(n):
            for j in range(n):
                # 时间距离越近 → 关联越强
                time_dist = abs(i - j)
                prior[i, j] = np.exp(-time_dist / 3.0)  # τ=3
        # 每行softmax归一化
        row_sums = prior.sum(axis=1, keepdims=True)
        return prior / row_sums
    
    def _cosine_series_attention(self, seq):
        """用余弦相似度近似自注意力"""
        n = len(seq)
        series = np.zeros((n, n))
        
        # 特征降维到emb_dim（PCA降噪）
        flat = seq.reshape(n, -1)
        
        for i in range(n):
            for j in range(n):
                sim = np.dot(flat[i], flat[j]) / (
                    np.linalg.norm(flat[i]) * np.linalg.norm(flat[j]) + 1e-8
                )
                series[i, j] = max(0, sim)  # ReLU过滤负相关
        
        # softmax归一化
        row_sums = series.sum(axis=1, keepdims=True) + 1e-8
        return series / row_sums
    
    def _kl_divergence(self, P, Q):
        """双向KL散度"""
        kl_pq = np.sum(P * np.log(P / (Q + 1e-8) + 1e-8), axis=1)
        kl_qp = np.sum(Q * np.log(Q / (P + 1e-8) + 1e-8), axis=1)
        return kl_pq + kl_qp  # (window,)
    
    def detect_anomaly(self, sequence, threshold_percentile=95):
        """返回异常分数最高的时间步和整体是否异常"""
        scores = self.compute_association_discrepancy(sequence)
        max_score = scores.max()
        
        # 自适应阈值：基于历史关联差异的百分位数
        if len(self.prior_cache) > 50:
            all_scores = np.concatenate(self.prior_cache[-50:])
            threshold = np.percentile(all_scores, threshold_percentile)
        else:
            threshold = 0.5  # 初始默认值
        
        return {
            'is_anomaly': max_score > threshold,
            'anomaly_score': float(max_score),
            'threshold': float(threshold),
            'anomalous_timestep': int(scores.argmax()),
            'timestep_scores': scores.tolist()
        }
    
    def learn_normal_pattern(self, normal_sequence):
        """增量学习正常模式——记录正常时序的关联差异分布"""
        score = self.compute_association_discrepancy(normal_sequence)
        self.prior_cache.append(score)
        
        # 仅保留最近200条
        if len(self.prior_cache) > 200:
            self.prior_cache.pop(0)
```

**对A7的具体价值：**
- 区分"正常但编号"的行情（比如ETH正常波动±2%）和"关联结构异常"的行情（比如BTC跌但ETF反而大量流入——价量关系反常）
- 不需要大量标注数据——无监督学习，从历史数据中自动学习"正常模式"
- 与F&G联动检测：F&G处于恐惧（<20）时，如果关联结构正常，是正常恐慌反弹机会；如果关联结构异常（局部≠全局），可能是系统性危机前兆

### 🟢 要点三：元学习自适应阈值 — 学会"如何设置告警阈值"

**理论背景：**
元学习（Meta-Learning, "learning to learn"）的核心思路是：**从多个学习任务中提取通用知识**，使模型面对新任务时只需要少量样本就能快速适应。

经典方法：
1. **MAML（Finn et al. 2017）**：学习模型参数的初始化 → 在新任务上只需1步梯度更新就能快速收敛
2. **Reptile（Nichol et al. 2018）**：比MAML更简洁，通过多次随机梯度下降后取平均值
3. **Metric-based（ProtoNet, Snell et al. 2017）**：学习一个好的特征空间，新类别用最近邻分类

**应用到A7的核心创新 — Market Regime Meta-Learning：**

A7的告警阈值受市场状态(regime)影响巨大：
- 高波动牛市（BTC日均±5%）：阈值需要大幅提高，否则每15分钟都在告警
- 低波动熊市（BTC日均±1%）：阈值需要降低，否则会漏掉关键信号
- 横盘震荡（BTC日±2%，但尾事件多）：阈值需要在不同维度上差异化

**元学习目标函数：**

```python
# 元学习任务定义
每个任务T_r = "在某个市场状态r下找到最优告警阈值θ_r"

元学习目标:
min θ E_{r~p(regime)} [ L_r(θ) ]

其中L_r(θ) = 在市场状态下使用阈值θ的告警损失
告警损失 = FP_rate(θ) + λ · FN_rate(θ)
（FN_rate权重λ=1.5，宁可漏报不可误报——符合A7的核心信条）
```

**A7的元学习阈值适配器（MAML-Adapted）：**

```python
import numpy as np
from sklearn.linear_model import Ridge

class MetaThresholdAdapter:
    """
    元学习阈值适配器
    在多个市场状态下学习如何快速调整阈值
    不依赖深度学习（用Ridge回归近似MAML内循环）
    """
    
    def __init__(self, lambda_reg=1.5):
        self.lambda_reg = lambda_reg  # FN权重
        self.regime_profiles = {}     # 每个市场状态的(特征→最优阈值)映射
        
        # 元知识：从市场统计量到阈值的基映射
        self.base_model = Ridge(alpha=1.0)
        self.base_model_trained = False
        
        # 阈值调整因子
        self.base_threshold = 10.0  # 默认基础阈值
        self.factor_range = (0.3, 2.5)  # 阈值可调整范围 [3, 25]
    
    def extract_regime_features(self, market_stats):
        """
        从市场统计量提取regime特征
        输入示例:
        {
            'btc_24h_volatility': 0.03,    # 24h波动率
            'btc_avg_5min_vol': 0.004,      # 5分钟平均波动
            'avg_funding_rate': 0.001,      # 平均资金费率
            'fng_index': 45,                # F&G指数
            'volume_24h_change': 0.15,      # 24h成交量变化率
            'dominance_trend': -0.02,       # BTC dominance趋势
            'top10_avg_return': 0.03,       # TOP10平均涨幅
            'spread_btc_eth': -0.01,        # BTC-ETH收益差
        }
        """
        # 关键特征
        features = np.array([
            market_stats['btc_24h_volatility'],
            market_stats['avg_funding_rate'],
            (market_stats['fng_index'] - 50) / 50,  # F&G归一化
            market_stats['volume_24h_change'],
            market_stats['btc_avg_5min_vol'] / 0.005,  # 相对基准波动
        ])
        return features.reshape(1, -1)
    
    def predict_optimal_threshold(self, market_stats):
        """
        元学习预测当前市场状态下的最优阈值
        """
        features = self.extract_regime_features(market_stats)
        
        if self.base_model_trained:
            # 有元知识 → 用基模型预测适配因子
            factor = self.base_model.predict(features)[0]
            factor = np.clip(factor, *self.factor_range)
        else:
            # 无元知识 → 使用F&G启发式规则
            fng = market_stats.get('fng_index', 50)
            vol = market_stats.get('btc_24h_volatility', 0.02)
            
            # F&G极端 → 降低阈值（更敏感）
            # 高波动 → 提高阈值（抑制误报）
            fng_factor = 1.0 - 0.3 * (50 - fng) / 50  # F&G低→因子低(敏感)
            vol_factor = 0.5 + vol * 20                 # 波动率高→因子高(抑制)
            
            factor = max(self.factor_range[0], min(self.factor_range[1], 
                       fng_factor * vol_factor))
        
        return self.base_threshold * factor
    
    def update_from_feedback(self, market_stats, zh_referenced, was_alerted):
        """
        用ZH隐式反馈做few-shot适应
        类似于MAML的"内循环更新"
        """
        features = self.extract_regime_features(market_stats)
        current_factor = None
        
        if self.base_model_trained:
            current_factor = self.base_model.predict(features)[0]
        
        # 计算"理想因子"——这次应该用了多少
        new_factor = current_factor or 1.0
        if was_alerted and not zh_referenced:
            # 误报：阈值太低 → 提高
            new_factor *= 1.05
        elif not was_alerted and zh_referenced:
            # 漏报：阈值太高 → 降低
            new_factor *= 0.95
        
        new_factor = np.clip(new_factor, *self.factor_range)
        
        # 累积训练数据（做meta-training用）
        regime_key = f"fng{market_stats['fng_index']//10}0_" + \
                     f"v{int(market_stats['btc_24h_volatility']*100)}"
        
        if regime_key not in self.regime_profiles:
            self.regime_profiles[regime_key] = []
        self.regime_profiles[regime_key].append({
            'feature': features[0],
            'optimal_factor': new_factor
        })
        
        # 每周重新训练基模型
        if sum(len(v) for v in self.regime_profiles.values()) > 20:
            self._meta_train()
    
    def _meta_train(self):
        """
        元训练：用所有regime的积累数据训练基模型
        让模型学到"给定市场特征→最优阈值的映射"
        """
        X, y = [], []
        for regime, profiles in self.regime_profiles.items():
            for p in profiles:
                X.append(p['feature'])
                y.append(p['optimal_factor'])
        
        if len(X) >= 5:
            self.base_model.fit(np.array(X), np.array(y))
            self.base_model_trained = True
```

**元学习 vs C3 MAB的差异：**

| 维度 | C3 MAB | C4 元学习 |
|:----|:------|:---------|
| 学习方式 | 每个阈值独立尝试 | 从市场特征到阈值的函数映射 |
| 适应速度 | 慢（每个阈值需要多次尝试） | 快（新市场状态→特征→预测阈值） |
| 跨状态迁移 | 不能（每个市场状态独立探索） | 能（从相似市场状态的知识迁移） |
| 需要数据 | ~100次尝试/状态 | ~5个样本就能适应新状态 |

### P1实施路径（立即可行，无外部依赖）

```python
# tools/extract_zh_feedback.py
# 从ZH的每日复盘文件中提取对A7告警的隐式反馈

def extract_feedback_for_alerts(alert_dir, zh_dir):
    """
    扫描历史告警和ZH复盘，建立(alert, was_referenced)数据集
    
    输入:
    - alert_dir: agents/a7/alert.md (或历史归档)
    - zh_dir: agents/zh/ 产出的复盘报告
    
    输出:
    - feedback.csv: [alert_date, alert_topic, alert_score, zh_referenced, zh_action_type]
    """
    import os, json, re
    from datetime import datetime, timedelta
    
    feedback = []
    
    # ① 收集所有历史告警
    alerts = []
    for f in sorted(os.listdir(alert_dir)):
        if f.endswith('.md'):
            with open(os.path.join(alert_dir, f)) as fh:
                content = fh.read()
            # 解析告警标题、时间、类型
            title_match = re.search(r'# A7舆情告警.*?(\d{4}-\d{2}-\d{2})', content)
            if title_match:
                alerts.append({
                    'file': f,
                    'date': title_match.group(1),
                    'content': content,
                    'topic': re.search(r'告警类型[：:]?\s*(.*?)[\n]', content),
                    'score': re.search(r'权重[：:]?\s*(\d+)', content),
                })
    
    # ② 扫描ZH复盘，看每个告警是否被引用
    for zh_file in sorted(os.listdir(zh_dir)):
        if not zh_file.endswith('.md'):
            continue
        with open(os.path.join(zh_dir, zh_file)) as fh:
            zh_content = fh.read()
        
        for alert in alerts:
            # 检查告警日期是否在复盘覆盖范围内
            # 检查ZH内容是否引用/提到该告警的事件
            mentioned = alert['topic'].group(1) in zh_content if alert['topic'] else False
            feedback.append({
                'alert_date': alert['date'],
                'alert_topic': alert['topic'].group(1) if alert['topic'] else 'unknown',
                'alert_score': alert['score'].group(1) if alert['score'] else '10',
                'zh_referenced': mentioned,
                'zh_date': zh_file.replace('.md', '')
            })
    
    return feedback
```
