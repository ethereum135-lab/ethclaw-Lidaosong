## 要点一：Smart Money ≠ Whale — 行为质量比钱包大小重要

**关键区别（来自Nansen两篇文章的共同结论）：**

| 维度 | Whale | Smart Money |
|:-----|:-----|:-----------|
| 定义依据 | 钱包余额大小 | 已实现PnL、胜率、交易历史 |
| 信号价值 | 有可能水平差 | 持续盈利的钱包 |
| 识别方式 | 余额>阈值 | 500M+地址数据库中的行为聚类 |
| $50M持有者 | ✅ 可能是Whale | ❌ 可能一直亏钱 |

**对A8的启示：** A8当前用「成交量>50K」作为信号门槛，等价于用「钱包大小」判断输入质量——大资金进来≠聪明资金进来。需要增加**行为质量代理指标**：

A8可实现的代理指标（**不追踪具体地址**）：

| 代理指标 | 实现方式 | 行为含义 |
|:---------|:---------|:---------|
| **多池共识度** | 同一币在DexScreener上n个独立池子同时有量 | 多个做市商/流动性提供者同时被买入=真实需求 |
| **买卖比分时模式** | buys/sells在1h内持续>1.5x而不是单点冲高 | 持续积累 vs 单点拉盘 |
| **交易笔数密度** | volume>$50K / txns<50笔 = wash_trading | 刷量行为过滤 |
| **池子年龄** | 新池(<24h)高量 + 买压 > 老池高量 | 新池可能是聪明钱先手，老池可能是追高 |

**实装建议：** 在a8_data_fetch.py步骤⑥中新增 `behavior_quality_score()` 函数，综合以上代理指标对INFLOW信号加/减权重：

```python
def behavior_quality_score(pair: dict) -> dict:
    """Smart Money行为质量代理评分（0-100）"""
    score = 50  # 基准分
    
    # 1. 买卖比持续性
    buys = pair.get('txns', {}).get('buys', {}).get('h24', 0)
    sells = pair.get('txns', {}).get('sells', {}).get('h24', 0)
    if buys + sells > 0:
        ratio_24h = buys / max(sells, 1)
        if ratio_24h > 1.5:
            score += 15  # 持续买压=高置信度
        elif ratio_24h < 0.5:
            score -= 15  # 持续卖压=无意义
    
    # 2. 交易笔数密度（排除刷量）
    volume_24h = pair.get('volume', {}).get('h24', 0)
    txns_24h = buys + sells
    if volume_24h > 50000 and txns_24h < 50:
        score -= 20  # 高量低笔数=疑似刷量
    
    # 3. 多池共识（通过pool_count传入）
    # score += pool_consensus * 3  # 3池=+9分
    
    return {
        "score": score,
        "verdict": "HIGH" if score >= 70 else "MID" if score >= 40 else "LOW",
        "details": {
            "buy_sell_ratio_24h": round(ratio_24h, 2) if buys + sells > 0 else None,
            "txns_24h": txns_24h,
            "score_drivers": []  # 标注正负驱动因素
        }
    }
```

## 要点二：集群共识 > 单点信号 — 用多源交叉验证替代地址追踪

**核心方法论（来自Nansen Hyperliquid Guide）：**

> "You are not looking for a single wallet to copy. You are looking for clusters: multiple high-performance wallets leaning the same way on the same market is a stronger signal than any individual trade."

**Nansen定义的三层Smart Money信号（对应perp交易）：**

| 层级 | 检测内容 | 对应A8信号 |
|:-----|:---------|:-----------|
| **Directional context** | 有记录的钱包群是净多还是净空 | INFLOW信号的方向（买/卖比） |
| **Conviction sizing** | Smart Money在跌时加仓还是涨时减仓 | INFLOW的持续性（是否每次下跌后有新量） |
| **Crowding risk** | 当方向一边倒+资金费率拉伸时，挤压已成形 | INFLOW信号的逆向使用 |

**对A8的启示：**

A8虽然无法追踪具体地址，但可以用**数据源的独立性**替代地址的独立性：

| Etherscan USDT大额转账 | ✅ 已接入 | 验证：稳定币入交易所=准备买 |
| Dune Whale Alert | ✅ 已接入 | 验证：ETH大额转账 |

**实装建议：** 不需要增加API调用，在现有save_snapshot阶段对INFLOW信号做后处理交叉验证——检查同一币种是否在Dune/Etherscan/HL OI数据中也有记录。如果某个INFLOW信号同时被其他源验证，在数据中加入 `cross_validated: true` 和 `verification_sources: ["etherscan", "hl_oi"]`。

```python
def cross_validate_inflow(snapshot: dict) -> list:
    """对INFLOW信号做多源交叉验证"""
    inflows = [s for s in snapshot.get('buy_signals', []) if s['type'] == 'INFLOW']
    
    # 提取MONEY_IN中涉及的币种（通过地址推断）
    whale_tokens = extract_whale_targets(snapshot.get('whale_signals', []))
    hl_active_markets = get_hl_active_markets(snapshot.get('hl_data', {}))
    
    for inflow in inflows:
        symbol = inflow['data'].split('|')[1]  # e.g. SOL
        sources = []
        
        if symbol in whale_tokens:
            sources.append('etherscan')
        if symbol in hl_active_markets:
            sources.append('hyperliquid')
        
        inflow['cross_verified'] = len(sources)
        inflow['cross_sources'] = sources
    
    return inflows
```

## 要点三：信号新鲜度区分 — 苏醒的鲸鱼比活跃的鲸鱼更有价值

**关键方法论（来自Nansen Solana Guide）：**

> "New wallet activity on a token that's been dormant for weeks tells a different story than the same activity on a token already trending."

**Nansen Solana Guide三问中的第三问：** 一个已休眠数周的代币突然出现新钱包活动 ≠ 同一个代币已经在上涨。**休眠苏醒信号的价值远高于持续活跃信号**，因为：

| 场景 | 信号含义 | A8加分 |
|:-----|:---------|:------:|
| **已持续高量3天+的币** | 追逐趋势中，可能已到后半段 | +5分(参考) |
| **休眠>72h后突然爆发高量** | Smart Money苏醒布局，领先指标 | **+15分**(高价值) |
| **新上池(<24h)高量+买压** | 先手资金进入，还无人知晓 | **+20分**(最高价值) |
| **成交量稳步放大(非脉冲)** | 持续积累，机构式进场 | +10分 |

**对A8的启示：** 当前A8每15分钟扫描一次，每次独立比对成交量>$50K。**没有跨轮次记忆**，不知道这个币24h前是什么样的活动水平。

**实装建议：** 新增 `data/a8/volume_history_cache.json`，记录每个被扫描币的24h历史成交量（只需存简单快照）：

```python
def calculate_freshness_score(symbol: str, chain: str, current_volume: float) -> dict:
    """计算信号新鲜度"""
    history = load_history()
    key = f"{chain}|{symbol}"
    prev = history.get(key, {})
    
    # 读取历史状态
    last_seen_volume = prev.get('last_volume', 0)
    last_seen_time = prev.get('last_seen_time', 0)
    hours_since_active = (time.time() - last_seen_time) / 3600 if last_seen_time else 999
    
    # 更新历史
    history[key] = {
        'last_volume': current_volume,
        'last_seen_time': time.time(),
        'peak_volume': max(prev.get('peak_volume', 0), current_volume)
    }
    save_history(history)
    
    # 新鲜度评分
    if last_seen_volume < 10000 and current_volume > 50000:
        return {"freshness": "dormant_awakening", "score": +15, "note": "休眠苏醒"}
    elif last_seen_time == 0:
        return {"freshness": "first_seen", "score": +12, "note": "首次发现"}
    elif current_volume > prev.get('peak_volume', 0) * 1.5:
        return {"freshness": "volume_spike", "score": +10, "note": "量能突破"}
    elif last_seen_volume > 50000 and current_volume > 50000:
        return {"freshness": "sustained", "score": +3, "note": "持续活跃"}
    else:
        return {"freshness": "normal", "score": 0, "note": "常规"}
```

**存储限制：** 只存最近7天的记录（每天清理一次）。每个币一条记录，`key: "eth|TOKEN"`，预估100个币只需几千字节。
