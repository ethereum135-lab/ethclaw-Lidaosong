### 集成示例（就这么简单）

```python
import ccxt

# 初始化
ex = ccxt.okx()  # 或 gate(), kucoin(), mexc()

# 行情
ticker = ex.fetch_ticker('BTC/USDT')
print(f'价格: {ticker["last"]}, 24h涨跌: {ticker["percentage"]}%')

# K线（30分钟，14根→RSI）
ohlcv = ex.fetch_ohlcv('BTC/USDT', '30m', limit=14)

# 资金费率
fr = ex.fetch_funding_rate('BTC/USDT:USDT')
print(f'费率: {fr["fundingRate"]}')

# 订单薄
ob = ex.fetch_order_book('BTC/USDT', 10)
spread = ob['asks'][0][0] - ob['bids'][0][0]
```
