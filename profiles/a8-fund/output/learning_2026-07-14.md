## 🔑 要点二（更快）：机构行为分解 — 不只看「净流入」总量，分解为三类行为

### 核心发现：同一时刻，对冲基金和银行在做完全相反的事

CoinShares Q1 2026报告最颠覆性的发现：

> **"The selling was highly concentrated. Hedge funds (-39% QoQ) and brokerages (-53% QoQ) accounted for 95% of the exposure reduction. Advisors trimmed 6% QoQ, while banks, governments, private equity, family offices, and insurance each added net exposure."**

这揭示了一个资金流向监控的核心原理：**只看「净流入/净流出」总量 = 信息损失。** 需要分解三个行为维度：

| 行为类型 | 特征（链上代理） | A8信号权重 | 信号价值 |
|:---------|:----------------|:----------:|:---------|
| **🔄 高换手机构**（类似对冲基金） | 频繁小额转账、交易所出入频繁、同一地址30天内≥20笔tx | 降权(0.5x) | 短期策略，不是方向性信号 |
| **🏦 长期配置**（类似银行/顾问） | 大额转账至冷钱包/DeFi、跨链桥大额单笔、地址交互协议<3个 | 升权(1.5x) | 方向性信号，领先2-4周 |
| **🏗️ 基础设施**（类似交易所/做市商） | 大量小额归集、合约交互高频、已知标记地址 | 参考(0.3x) | 系统行为，非市场方向 |

### A8的落地方式

A8不需要追踪具体地址？但可以给现有Etherscan大额转账加**行为标签聚类**：

```python
# 现有Etherscan tokentx返回的每个转账 → 按行为模式分类
def classify_tx_behavior(tx: dict, address_history: dict) -> str:
    """根据地址历史交互模式判断这是哪类行为"""
    from_addr = tx['from']
    to_addr = tx['to']
    value = float(tx['value'])
    
    # 获取地址历史（30天窗口）
    history = address_history.get(from_addr, [])
    history += address_history.get(to_addr, [])
    
    tx_count_30d = len(history)
    unique_protocols = len(set(h.get('contract', '') for h in history))
    avg_tx_value = sum(abs(h.get('v', 0)) for h in history) / max(tx_count_30d, 1)
    
    # 高频低额 → 做市商/交易所行为
    if tx_count_30d > 100 and avg_tx_value < 50000:
        return 'infrastructure'    # 0.3x
    
    # 高额低频 → 长期配置行为（银行/主权/家族办公室）
    if value > 500000 and tx_count_30d < 30 and unique_protocols < 3:
        return 'long_term'         # 1.5x
    
    # 中频中额 → 对冲/策略型
    if tx_count_30d >= 20 and value > 100000:
        return 'tactical'          # 0.5x
    
    return 'unknown'               # 1.0x（默认）
```

**对A3的影响：** 携带`behavior: "long_term"`标签的MONEY_IN信号 → A3在原有基础上+10分（领先信号，机构在做长线配置）。携带`behavior: "tactical"`标签 → 只加+3分（短期策略，可能是套利不是建仓）。

### 为什么这比「追踪特定地址」更好

这是老李纠正方向的自然延伸：

```
老李纠正：不要找谁在买 → 找哪有大钱进来
第四轮2/4：  不要追特定地址 → 分解行为模式 → 同类聚类
```

不需要建地址库，不需要知道地址的持有者身份。只需要：
1. 观察这个地址的**交互模式**（频率、金额、协议数）
2. 按照模式分配到三个行为分类
3. 仅当**同一分类中多个地址同时向同一方向**时才算信号

这与Nansen的集群方法论一致（见第四轮1/4）— 个体行为不可靠，集群共识可信。
